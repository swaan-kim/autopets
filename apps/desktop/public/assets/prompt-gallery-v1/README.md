# 프롬프트 갤러리 정적 예시

2026-11-04 소유자 승인으로 내장 `image_gen`을 4회 호출하여 제작했다. 기존 제품 AI 원장 77턴과 별도인 제작용 호출 4회이며, 이번 후속 작업은 소유자가 이전 턴 상한을 해제했다. 제품 실행 중 이미지 생성이나 주기적 AI 호출을 추가하지 않았다.

| 파일 | 용도와 확인 |
| --- | --- |
| product.webp | 가상 mori 제품의 자연광 사진 예시. 병·라벨·구도 확인 |
| coast.webp | 해변 영상용 정지 참고 이미지. 실제 파도 영상·카메라 이동을 생성한 결과가 아님 |
| poster.webp | 가상 행사 포스터. SLOW SUNDAY, OPEN GARDEN, 날짜·시간 문구 확인 |
| orbit.webp | 제품 영상용 정지 참고 이미지. 실제 제품 회전이나 영상의 형태 보존 검증이 아님 |

모든 원본은 1536×1024 PNG이며 제작 환경과 작업 공간의 비공개 원본 폴더에 보존했다. 제품용 WebP는 크기·구도 변경 없이 품질 88로 인코딩했다. `manifest.json`에 내장 도구 구분, 호출 수, 정확한 영문 제작 프롬프트, 원본·제품 파일 SHA256과 크기를 기록했다. 도구가 모델 식별자를 반환하지 않아 특정 모델 이름이나 재현 seed를 기록하지 않았다.

앱 상세 화면은 간단한 사용자 요청 예시와 실제 이미지 제작 원문을 구분한다. 짧은 요청은 사용자의 제품·행사로 바꾸기 위한 안내이며 동일한 결과를 보장하지 않는다. 자산 로딩 실패 시 기존 SVG 구도 예시를 표시하고, 영상 참고 이미지를 실제 영상 재생으로 표시하지 않는다.
