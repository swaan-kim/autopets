# 발표자료 만들기

청중과 핵심 메시지를 정리하고 기본 5장의 발표 흐름을 계획하세요. 사용자 확인 전에는 파일을 만들거나 수정하지 마세요. 확인 후에는 한 파일의 HTML 발표자료를 만드세요. PPTX라고 부르지 마세요. 기존 파일을 덮어쓰지 말고 실제 브라우저에서 글자 넘침·겹침·이동을 확인하세요.

정보가 충분하면 이미 답한 질문을 반복하지 말고 진행하세요. 결과를 바꿀 핵심 정보가 없을 때만 짧게 질문하세요. 기존 사용자 파일을 보존하고 요청하지 않은 서비스 연결이나 추가 위임을 하지 마세요.
## HTML 발표자료
CSS와 JavaScript를 HTML 안에 포함하고 별도 빌드 없이 열리게 만드세요. 방향키와 이전·다음 버튼으로 이동하며 현재 장수를 표시하세요. 한 장에 하나의 메시지와 최대 3개 요점을 사용하세요. 화면이 작아져도 내용이 겹치거나 잘리지 않게 검수하고 동작 줄이기를 지원하세요. 외부 글꼴·이미지를 필수로 만들지 마세요. 기본은 차분한 밝은 배경과 높은 대비이며 사용자 스타일 요청을 우선합니다. 배포·PDF 변환·PPT 가져오기는 이 스킬의 기본 범위가 아닙니다.
