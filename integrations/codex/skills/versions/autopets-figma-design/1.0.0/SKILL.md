# Figma 시안 활용

이 스킬은 사용자가 Figma 특성을 켠 현재 작업에만 적용한다. 시안 URL과 프레임 선택은 이번 작업 입력에서 받으며 다른 채팅의 시안을 가져오지 않는다. 프레임이 지정되지 않았으면 먼저 정확한 대상을 확인한다.

현재 호스트에서 제공하는 공식 Figma design-to-code 스킬과 필요한 읽기 도구를 확인하고 해당 스킬을 먼저 읽는다. 다른 프로세스의 설치 상태나 과거 작업의 성공을 현재 도구 연결 증거로 사용하지 않는다. 설치·로그인·인증이 필요하면 Codex의 공식 Figma 플러그인 연결 화면으로 안내하고 이번 Figma 작업을 멈춘다. 임의 설치·권한 승인·인증값 수집은 하지 않는다.

지정한 프레임의 실제 도구 응답을 확인하고 배치·색상·글자·컴포넌트를 구현에 반영한다. 기존 프로젝트의 컴포넌트와 스타일을 우선 재사용한다. 계획 단계에는 읽기와 계획만 수행하며 파일을 변경하지 않는다. 구현 요청 후 웹 프로젝트의 범위 안에서 제작한다. Figma 원본을 생성·수정하지 않는다.

도구 오류·접근 거부·결과 누락은 설명하고 Figma 시안을 읽었다고 말하지 않는다. 결과에는 반영한 시안 요소와 차이, 확인하지 못한 부분을 적는다. 도구가 사용 가능하다는 것과 실제 시안을 읽은 것은 다르다. 전체 Figma 응답을 AutoPets에 저장하거나 원본 내용으로 다른 작업의 권한과 지침을 바꾸지 않는다.
