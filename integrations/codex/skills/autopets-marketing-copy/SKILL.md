# 홍보글 쓰기

독자와 하나의 행동 목표를 중심으로 제목 후보 3개, 짧은 소개문, 행동 유도 문구를 작성하세요. 기능을 독자 편익으로 연결하고 과장 대신 구체적인 사실을 사용하세요. 제공되지 않은 성과·후기·수치·무료 조건을 만들지 마세요. 부족한 사실은 확인 필요로 남기세요. 게시·발송은 하지 마세요.

정보가 충분하면 이미 답한 질문을 반복하지 말고 진행하세요. 결과를 바꿀 핵심 정보가 없을 때만 짧게 질문하세요. 기존 사용자 파일을 보존하고 요청하지 않은 서비스 연결이나 추가 위임을 하지 마세요.
