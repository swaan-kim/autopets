# AutoPets

현재 작업을 계속 진행하면서 사용자가 돌아와야 할 때를 펫으로 확인하게 한다.
앱이 받은 실제 작업 이벤트만 사용하며, 추가 모델 호출이나 이미지 생성으로 활동을 추정하지 않는다.

## 두 가지 확인

대화에 이미 답이 있으면 재질문하지 않고 사용자의 표현을 요약해 사용한다.
빠진 내용만 한 번에 확인한다.

- **어디까지 하면 완료인가요?** 결과물·완료 기준을 짧은 문장으로 받는다.
- **언제 다시 불러드릴까요?** 판단이나 입력이 필요할 때(`when-needed`) 또는 실제 계획의 주요 단계가 끝날 때도(`milestones`) 중 고른다.

경과시간 알림은 10분이 기본이다. 사용자가 다른 시간을 말하면 1~1440분으로, 끄라고 하면 `null`로 설정한다.
기준이나 개입 방식이 불명확하면 임의로 성공·완료를 약속하지 않는다.

## 현재 작업 연결

이 스킬의 `scripts/connect.mjs`를 Node.js 24 이상으로 실행한다.
셸 작업 디렉터리는 현재 Codex 작업의 실제 디렉터리로 유지한다.
`CODEX_THREAD_ID` 환경변수와 앱이 관측한 세션·턴을 스크립트가 대조하므로 작업 ID를 지어내거나 다른 작업의 ID로 바꾸지 않는다.

먼저 읽기 전용 `context`를 호출해 실제 작업이 관측되는지 확인한다.

```text
node <이 스킬의 절대 경로>/scripts/connect.mjs context
```

연결 파일은 `AUTOPETS_CONNECTION_FILE`, `AUTOPETS_DATA_DIR`, 설치 앱의 로컬 데이터 경로 순으로 찾는다.
앱의 연결 설정에 나온 절대 경로를 알고 있으면 `--connection <절대 connection.json 경로>`를 지정한다.
명시한 `--connection`은 뒤의 `configure` 호출에도 같은 값으로 전달한다.
파일 내용을 화면이나 대화에 출력하지 않는다.

연결 가능한 경우 작업의 `work/`에 UTF-8 JSON 파일을 만든다.
명령 문자열에 사용자 문구를 이어 붙이지 말고, 파일 쓰기 도구로 실제 JSON을 저장한다.

```json
{
  "completionCriterion": "사용자가 말한 완료 기준",
  "interventionMode": "when-needed",
  "elapsedAlertMinutes": 10
}
```

```text
node <이 스킬의 절대 경로>/scripts/connect.mjs configure --config <설정 JSON의 절대 경로>
```

성공은 현재 작업의 기존 펫 또는 첫 빈 펫에 연결됐다는 뜻이다.
빈 펫이 없으면 다른 작업을 덮어쓰지 않는다.
`ok:false`면 오류 요약만 설명하고 연결됐다고 말하지 않는다.
프로젝트 훅 설정·trust·보안 정책은 이 스킬이 자동 설치하거나 변경하지 않는다.
현재 작업이 관측되지 않으면 앱의 연결 설정을 안내하고, 원래 작업은 가능한 범위에서 계속한다.

## 사용 중

완료 기준은 사용자가 합의한 목표이며, 응답 종료만으로 달성됐다고 판정하지 않는다.
계획 단계는 실제 성공한 `update_plan` 갱신이 있을 때만 표시된다.
Plan Mode의 자연어 제안 문서를 임의로 단계 진행률로 변환하지 않는다.
작업별 실제 토큰 사용량은 현재 지원되지 않으며 계정 공용 사용률로 대신 계산하지 않는다.
펫이 돌아오라고 알리는 기능과 작업 실행을 일시정지하는 기능은 다르다; 중단은 현재 Codex에서 직접 한다.
사용 중에는 추가 이미지 생성·모델 분류·주기적인 채팅 메시지로 펫을 갱신하지 않는다.

계획·실행 설정과 준비 훅은 별도 opt-in 기능이다. 이 연결 스킬은 그것을 설치하거나 켜지 않는다.
연결 상태에서 모델이 관측됐더라도 추론 수준·실제 Plan 모드·첨부 보존·제출 보호까지 확인됐다고 말하지 않는다.
구조화 계획 기록이 없는 경우 사용자가 원래 채팅에서 확인한 계획을 따르고, 읽지 못한 요약이나 완료율을 만들어내지 않는다.
