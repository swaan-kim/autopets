# AutoPets 시작

“제작 펫 연결”, “제작 펫으로 작업”, “펫 상태 확인”과 현재 펫 계획의 명시적 후속 구현은 설치된 연결 도구의 `integrations/codex/skills/autopets/references/explicit-pet.md`를 확인한다. 호스트의 현재 작업 ID와 폴더를 유지하며 `scripts/pet.mjs`로 연결·설정을 재조회한다. 훅 허용은 이 연결의 선행 조건이 아니다. 훅 수신이나 실제 모델 적용을 연결 성공만으로 주장하지 않는다.

제품 주소는 https://swaan-kim.github.io/autopets/start/ 이다. 요청과 결과는 기존 AI 채팅에 남기고, 별도 채팅이나 계정을 만들지 않는다.

- **Windows 로컬 실행 도구가 있음:** 먼저 `%LOCALAPPDATA%/AutoPets/connector/runtime/node.exe`와 같은 설치의 `integrations/codex/bootstrap/start.mjs`를 확인한다. `AUTOPETS_HOME`이 명시돼 있으면 그 경로를 사용한다. 정상 설치는 해당 시작 도구로 실행하며 재다운로드하지 않는다. 작업 경로와 실제 `CODEX_THREAD_ID`를 보존한다.
- **처음 설치:** 제품 사이트가 제공하는 고정 버전 설치 EXE와 검증 정보를 확인한다. 그 버전의 검토 가능한 `fetch-installer.ps1`을 파일로 받은 뒤 해시·Authenticode 검사 경로로 실행한다. 원격 스크립트를 즉시 평가하거나 소스 빌드를 설치로 대신하지 않는다. 설치 후 앱의 같은 연결 화면으로 이어간다.
- **웹·클라우드 또는 미지원 OS:** 제품 사이트의 설치 버튼을 안내한다. 원격 실행 환경을 사용자 PC로 간주하지 않는다.

공개 설치 파일이 없으면 배포 준비 중임을 설명한다. 스킬/플러그인 등록을 앱 설치나 연결 성공으로 표시하지 않는다. 리뷰 빌드나 임의 최신 파일을 공개 버전으로 대체하지 않는다.

앱 준비·스킬 준비·실제 펫 작업을 따로 확인한다. 사용자가 앱에서 연결하면 채팅에서 “제작 펫 연결”을 보내도록 안내한다. 새 스킬 발견에 호스트 재시작이 필요하면 진행 중 작업을 끊지 않고 안내한다. 작업을 재전송하지 않고 설치 전 진행 상태를 만들어내지 않는다.

제작 펫의 초기 프로필은 가볍게이며 실제 가용 모델을 확인한 뒤 적용한다. 모델·추론·제출 보호는 각각 검증된 것만 설명한다. 펫 메뉴의 도움 끄기·숨기기·종료를 안내한다. 종료한 앱을 훅이나 주기 호출로 다시 띄우지 않는다.
