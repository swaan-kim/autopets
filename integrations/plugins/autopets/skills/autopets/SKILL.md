# AutoPets 시작

“제작 펫 연결”, “제작 펫으로 작업”, “펫 상태 확인”과 현재 펫 계획의 명시적 후속 구현은 설치된 연결 도구의 `integrations/codex/skills/autopets/references/explicit-pet.md`를 확인한다. 호스트의 현재 작업 ID와 폴더를 유지하며 `scripts/pet.mjs`로 연결·설정을 재조회한다. 훅 허용은 이 연결의 선행 조건이 아니다. 훅 수신이나 실제 모델 적용을 연결 성공만으로 주장하지 않는다.

제품 주소는 https://swaan-kim.github.io/autopets/start/ 이다. 기본 흐름은 **이 채팅에서 호출 → 앱에서 펫 선택·설정 적용 → 같은 채팅에서 작업**이다. 앱은 선택·설정·상태를 담당하고 할 일과 결과는 Codex 채팅에 남긴다. 펫 ID·역할 지침·모델 설정을 사용자에게 복사시키지 않는다.

- **Windows 로컬 실행 도구가 있음:** 먼저 `%LOCALAPPDATA%/AutoPets/connector/runtime/node.exe`와 같은 설치의 `integrations/codex/bootstrap/start.mjs`를 확인한다. `AUTOPETS_HOME`이 명시돼 있으면 그 경로를 사용한다. 정상 설치는 해당 시작 도구로 실행하며 재다운로드하지 않는다. 작업 경로와 실제 `CODEX_THREAD_ID`를 보존한다.
- **처음 설치:** [공식 설치 계약](https://github.com/swaan-kim/autopets/blob/main/INSTALL.md)을 읽고 게시된 고정 버전·설치기·해시·서명 상태를 대조한다. 안정판과 미서명 개발 미리보기의 manifest·helper를 섞지 않는다. 미서명 시험판 설치 선택과 실제 보안 정책을 존중한다. 검토한 helper를 로컬 파일로 실행하며, 원격 문자열 즉시 평가나 소스 빌드로 대체하지 않는다. Codex 자체 설치·로그인은 별도 선행 조건이다.
- **웹·클라우드 또는 미지원 OS:** 제품 사이트의 설치 버튼을 안내한다. 원격 실행 환경을 사용자 PC로 간주하지 않는다.

해당 채널에 공개 설치 파일이 없으면 배포 준비 중임을 설명한다. 안정판이 없다는 이유로 개발 미리보기를 안정판으로 안내하지 않는다. 스킬/플러그인 등록은 Windows 앱 설치와 다르며, 리뷰 빌드나 임의 최신 CI 파일을 공개 버전으로 대체하지 않는다.

앱 준비·스킬 준비·현재 채팅 연결·실제 펫 작업을 따로 확인한다. 준비된 현재 채팅은 다시 연결하라고 요구하지 않는다. 연결 후 앱에서 펫 적용을 재조회한 뒤 같은 채팅의 명시적 작업 요청으로 이어간다. 호출만 요청했으면 새 하위 작업을 실행하지 않는다. 새 스킬 발견에 호스트 재시작이 필요하면 진행 중 작업을 끊지 않고 안내한다. 작업을 재전송하지 않는다.

제작 펫의 초기 프로필은 가볍게이며 실제 가용 모델을 확인한 뒤 적용한다. 모델·추론·제출 보호는 각각 검증된 것만 설명한다. 펫 메뉴의 도움 끄기·숨기기·종료를 안내한다. 종료한 앱을 훅이나 주기 호출로 다시 띄우지 않는다.

완료는 실제 실행과 결과 반환을 근거로 한다. 스킬 확인·결과 품질·첫 실행 지침의 독립 증거가 부족하면 그 한계를 유지한다. 부모 채팅 모델 변경, 모든 요청 자동 처리, 실제 Plan 강제, Steam·다른 AI 연결을 현재 기능으로 설명하지 않는다.
