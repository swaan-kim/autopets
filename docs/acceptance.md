# v1 검증 기록

2026-09-20. 실제 Codex 이벤트, 시험 서버, 브라우저 fixture를 구분한다. 이 문서는 최초 CI 실행 전 확인한 결과다. Windows 빌드 결과는 해당 commit의 Actions 실행 기록을 확인한다.

## 확인한 결과

- [x] TypeScript 타입 검사와 Vite 프로덕션 빌드.
- [x] Node 어댑터·스킬 22개 테스트: 실제 child process, stdin/stdout, loopback 인증, 작업·턴 바인딩, 멱등 설정, 미할당 슬롯, 설치·해제 보존, 한글 경로.
- [x] Native 화면의 브라우저 fixture 6개 시나리오, page error 0개. 실제 네이티브 창 검증은 아님.
- [x] 소개 목업 8개 조작 검사: 선택한 작업 복귀, 실행을 멈추지 않는 알림, 확인 후 중복 방지, 토큰 비활성, 두 번째 작업 격리, 연결 불명 구분, 다시 알림 전 조용함, 5분 후 다시 알림.
- [x] 같은 HTML에서 1080×1350 PNG 3장 출력·시각 검수. 목업은 인라인 자산만 사용하고 외부 연결을 CSP로 차단한다.
- [x] 64×64 투명 PNG 8프레임, 256×128 스프라이트, 정수 배율 표시. 이미지 생성은 제작 시 한 번 수행했으며 실행 중 추가 호출 없음.
- [x] Rust 포맷과 locked/offline Cargo metadata 검사.
- [ ] Rust 테스트 31개 작성; 로컬 테스트 본문은 Windows 앱 제어 4551로 실행하지 못함. CI에서 실행한다.
- [x] Windows 테스트·NSIS 설치 파일·companion ZIP·SHA-256 생성 workflow 준비.

## 실제 환경에서 남은 확인

- [ ] GitHub Actions의 해당 commit에서 Rust 테스트·NSIS 빌드 성공 및 artifact 확인.
- [ ] 설치·실행·종료·재실행, 서명과 사용자 PC의 실행 허용 여부.
- [ ] 다른 앱 위에 뜨는 독립 투명 창, 포커스 유지, 이동, 트레이, DPI 100/150/200%, 다중 모니터.
- [ ] 정상적인 Codex 훅 trust 이후 실제 현재 작업의 이벤트 수신과 스킬 연결.
- [ ] 같은 작업 재호출 시 중복 없음, 작업당 하나·최대 세 개, 다른 작업을 덮어쓰지 않음.
- [ ] 실제 성공한 계획 갱신, 도구 이벤트, 권한 필요, 응답 도착, 오류, 연결 불명 구분.
- [ ] 실제 경과 시간의 단발 알림·다시 알림·재시작 이후 중복 방지.
- [ ] 자동 작업 복귀는 현재 미연결. Native는 작업 ID·경로를 제공하고 목업에서만 시연 화면으로 복귀한다.
- [ ] 작업별 실제 토큰 집계 연결. 현재 설정 비활성, 계정 공용 사용률 대입 없음.
- [ ] 타겟 사용자 5명 인터뷰. 이번 범위는 자료 준비이며 모집·발송·인터뷰를 수행하지 않음.

## 제외한 기능

펫에서 직접 승인, 자동 일시정지, 모델 변경, 반복 추론을 통한 상태 분류, 지속적인 코칭은 v1 기능이 아니다. 내부에 남은 이전 승인 큐 코드는 호환용이며 production에서 활성화하지 않는다.
