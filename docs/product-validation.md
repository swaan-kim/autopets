# AutoPets 제품 콘셉트 / 사용자 검증

## 한 문장

**AI는 맡겨두고, 내 일에 집중하세요.**

작업 창을 열지 않아도 다른 앱 위의 작은 펫으로 지금 하는 일과 확인할 순간을 살펴본다.

**대상:** Codex에 리서치·문서 작업을 맡기고 다른 업무를 병행하는 비개발직 실무자.

**불편:** 일이 진행되는지, 응답이 왔는지, 내 결정이 필요한지 확인하기 위해 작업 창을 반복해서 열고 해당 작업을 찾는다.

**제안:** 채팅에서 부른 작은 픽셀 강아지가 독립 창으로 머무른다. 현재 단계와 확인할 순간을 알려주고, 누르면 관련 작업 정보를 펼쳐준다.

귀여움은 켜 두고 싶은 이유다. 핵심 제안은 **창을 덜 오가요 · 확인할 때를 알아요 · 여러 작업도 안 헷갈려요**라는 세 가지 편리함이다. 현재 활동과 확인 사유, 작업 이름을 함께 보여줘 상태를 보러 창을 반복해서 여는 번거로움을 줄이고자 한다. 실제 작업 자동 복귀는 연동 검증 중이므로 핵심 강점으로 약속하지 않는다. 시간·토큰 절감과 목표 성공률 향상은 아직 검증하지 않은 기대 효과이며, 결과 수치로 홍보하지 않는다.

## 체험 흐름

**펫 부르기 → 완료 기준 정하기 → 내 일 계속하기 → 필요할 때 확인**

1. `$autopets`와 작업 요청을 입력한다. 이미 같은 작업에 연결된 펫은 다시 만들지 않는다.
2. 기존 요청에서 완료 기준을 제안하고 확인받는다. 개입 시점은 ‘막히거나 결정이 필요할 때’가 기본이며 ‘주요 단계마다’를 선택할 수 있다.
3. 사용자는 Notion에서 회의를 준비한다. 경쟁사 비교와 고객 인터뷰 요약에 연결된 두 펫의 행위가 달라진다.
4. 펫을 누르면 완료 기준, 현재 단계, 계획 목록, 최근 갱신 상태가 나온다.
5. 기본 10분 알림을 받으면 상태를 보고 판단한다. 확인 또는 5분 뒤 다시 알림을 선택할 수 있다. 알림은 작업을 멈추지 않는다.
6. 클릭 목업에서는 선택한 작업의 Codex 시연 화면으로 이동한다. 실제 제품의 직접 복귀는 별도 연동 검증이 필요하다.

## 제작물 사용법

- `index.html`: 인터넷 없이 열리는 그림 소개와 클릭 목업. 처음에는 **01 한눈에 소개**가 가로로 크게 열리고, **02 사용 흐름**, **03 편리한 점** 탭도 보인다. **직접 체험하기**로 클릭 목업을 시작하고, 세 가지 편리함 카드를 누르면 관련 체험 장면으로 이동한다. 체험 화면 아래 상태 예시와 `+1분 시연`으로 오류·응답 도착·연결 불명·시간 알림을 확인할 수 있다. 재설정하면 처음 체험 흐름으로 돌아간다.
- `00-overview-wide.png`: 다른 앱에서 일을 계속하는 사용자와 작업 상태를 보여주는 두 펫을 중심으로, 세 가지 편리함과 전체 사용 흐름을 담은 가로 소개.
- `01-overview.png`: 같은 핵심 장면·세 가지 편리함·4단계 흐름을 세로로 담은 소개.
- `02-user-flow.png`: 펫 부르기 → 완료 기준 정하기 → 내 일 계속하기 → 필요할 때 확인하기를 그림으로 보여준다. 마지막 장면의 자동 작업 복귀는 시연이라고 표시한다.
- `03-benefits.png`: **창을 덜 오가요 · 확인할 때를 알아요 · 여러 작업도 안 헷갈려요**라는 세 가지 편리한 점을 보여준다.
- `brand/autopets-mark.svg`, `brand/autopets-mark.png`: 강아지 심볼. `brand/autopets-logo.svg`, `brand/autopets-logo.png`: 심볼과 AutoPets 워드마크. 새 로고 SVG는 코드로 제작했다.
- `sprite-source.png`: 내장 ImageGen으로 생성한 원본 8프레임 아틀라스. 앱용 64×64 프레임은 소스 패키지의 `public/assets/pet`에 있다.
- `asset-provenance.md`: 제작 프롬프트, 참고 출처, 이미지 처리 방식.

가로 소개 한 장은 1280×800, 세로 소개 세 장은 각각 1080×1350이며 같은 HTML에서 출력한다. 최신 묶음 파일은 `AutoPets-promo-v3.zip`이다. 이번 소개 개편에서는 기존 픽셀 강아지를 재사용했고 추가 AI 이미지 생성은 하지 않았다.

모든 소개 이미지는 제품 콘셉트와 시연 데이터를 표시한다. 실제 작업 자동 복귀는 연동 검증 중이다. 목업은 실제 Codex·Notion 작업을 수행하거나 외부로 전송하지 않는다. 소스 앱은 수신한 실제 데이터만 사용하며 목업 데이터를 연결하지 않는다.

## 첫 버전의 경계

자동 일시정지, 모델 변경, 지속적인 목표 이탈 코칭, 직접 승인·거절은 포함하지 않는다. 토큰 알림은 실제 작업별 사용량이 연결되기 전까지 ‘측정 미연결’로 표시한다. 계정 전체 사용률을 작업별 토큰 사용량으로 표시하지 않는다. 기존 Codex의 권한·승인 정책을 바꾸지 않는다.

계획이 바뀌어도 새 이미지를 만들지 않는다. 실제 계획과 도구 이벤트를 미리 정한 동작에 연결하고, 알 수 없는 행위는 ‘진행 중’으로 표시한다. 대화나 화면을 반복 분석하는 모델 호출을 추가하지 않는다. 스킬을 읽고 시작 질문을 처리하는 데에는 기존 Codex 호출 비용이 든다.

## 5분 인터뷰 — 설명보다 행동 먼저

**진행자 준비:** 대상은 최근 2주 안에 Codex에 리서치 또는 문서 작업을 맡긴 경험이 있는 사람 5명. 처음부터 귀여움·토큰 절약·생산성 향상을 강조하지 않는다. 설치나 결제 의향만으로 수요가 검증됐다고 판단하지 않는다. 참여자 모집과 메시지 발송은 별도 작업이다.

| 시간 | 진행 | 기록할 내용 |
|---|---|---|
| 0:00–1:00 | “최근 Codex에 일을 맡기고 다른 일을 했던 때를 떠올려 주세요. 진행이나 응답을 어떻게 확인했나요?” | 구체적인 작업, 확인 계기, 확인하려고 돌아간 경험. 그런 불편이 없었다는 답도 그대로 기록. |
| 1:00–2:00 | 가로 소개 `00-overview-wide.png`를 설명 없이 보여주고 “지금 무슨 일이 일어나고 있나요? 이걸 쓰면 무엇이 편해질까요?” | 독립 펫 인지, 두 작업 구분, 현재 행위와 전체 흐름 이해, 본인이 이해한 편리함. |
| 2:00–3:00 | **직접 체험하기**로 목업을 열고 “경쟁사 비교가 어디까지 됐는지 확인해 주세요.” | 첫 클릭, 단계 찾기, 다른 작업과 혼동, 도움 요청 여부. |
| 3:00–4:00 | 시간 알림 장면을 보여주고 “지금 무엇을 할 수 있나요? 어떤 작업으로 돌아가나요?” | 시간 알림을 오류/중단으로 오해하는지, 같은 작업 복귀 이해, 다시 알림 선택. |
| 4:00–5:00 | “다음 주 어떤 업무에서 켜 둘 것 같나요? 오히려 방해가 되는 부분은요?” | 구체적인 재사용 상황, 기존 방식 대비 가치, 크기·움직임·알림 부담. |

선택 후속 질문: “펫이 지금 하는 일을 잘못 알려주면 어떻게 알아차릴 수 있을까요?”, “시간 기준은 몇 분이 적절한가요?”, “토큰 숫자는 판단에 도움이 되나요?”
