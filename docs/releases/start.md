# AutoPets 시작하기

**Windows 설치 버튼 또는 “AutoPets 설치하고 켜줘”. 같은 앱으로 시작합니다.**

현재는 **개발 미리보기**입니다. [GitHub Pre-release](https://github.com/swaan-kim/autopets/releases)의 설치 EXE·체크섬·빌드 기록으로 검토할 수 있습니다. 미서명 파일은 Windows 보안 정책에 따라 차단될 수 있으며, 차단되면 실행을 중단합니다. 공개 서명 Release와 최신 사용자 흐름 검증이 끝나기 전에는 안정판 설치 버튼과 자동 업데이트를 활성화하지 않습니다. [제품 소개 원본](../start/index.html) · [안정판 배포 상태](channel.json)

## 개발 미리보기 설치

1. Release의 **Pre-release** 표시와 검사·제한 사항을 읽습니다. 소스 ZIP은 설치기가 아닙니다.
2. `AutoPets_0.1.0_x64-setup.exe`와 `SHA256SUMS.txt`, `BUILD.txt`를 받습니다. 같은 앱 버전이어도 Release 태그와 SHA-256으로 구분합니다.
3. 파일의 SHA-256을 대조하고 일반 설치를 진행합니다. 정책 차단이나 발행자 확인이 필요하면 그 지점에서 멈춥니다. 보안 설정 해제를 요구하지 않습니다.
4. 앱에서 **이 펫으로 시작 → Codex에 펫 준비 → 시작 요청 복사**로 진행합니다. 기존 Codex 채팅에 직접 요청을 보내고 계획을 확인한 후 구현을 요청합니다.

이 미리보기는 `channel.json`을 이용한 안정판 자동 설치·업데이트 경로에 등록하지 않습니다. 기존 데이터 경로는 유지하며, 최신 UI 펫의 전체 실환경 흐름과 보안 정책을 유지한 배포 검증은 [남은 계획](../roadmap/mvp-execution.md)을 따릅니다.

## 설치 버튼

공개 후에는 제품 사이트에서 Windows 설치 EXE 하나를 받습니다. Git·Node·Rust를 따로 설치하지 않습니다. 앱과 런타임·연결 도구·라이선스·오프라인 WebView2를 함께 설치합니다.

설치 후 **앱 준비 → AI 연결 → 첫 작업 확인**으로 이어집니다. AI 연결은 앱에서 선택하고, 필요한 훅 신뢰·로그인·재시작 화면을 안내합니다. 설치 프로그램 자체는 AI 설정을 바꾸지 않습니다.

## AI에서 요청

> 이 링크의 AutoPets 설치하고 켜줘.

Windows 로컬에서 실행할 수 있는 AI는 먼저 기존 설치를 확인합니다. 정상이면 재다운로드 없이 실행합니다. 첫 설치는 사이트와 같은 `channel.json`의 고정 EXE를 사용합니다.

1. 검토한 `channel.json`과 같은 배포의 `fetch-installer.ps1`을 파일로 받습니다. 공개 버전이 없으면 공개 전이라고 설명합니다.
2. 스크립트 내용을 확인한 뒤 `-ManifestPath <확인한 JSON 경로>`로 실행합니다. 고정 URL·SHA-256·Authenticode 발행자 검사를 통과한 파일만 실행합니다. 원격 문자열을 즉시 평가하지 않습니다.
3. 설치 후 같은 앱의 AI 연결 화면으로 이어집니다. 현재 작업을 재전송하거나 설치 전 진행 상태를 만들어내지 않습니다.
4. 앱 준비·AI 연결·지침 전달·설정 보호를 각각 실제 증거대로 설명합니다.

웹·클라우드처럼 PC에 설치할 수 없는 AI는 [제품 사이트](https://swaan-kim.github.io/autopets/start/)를 안내합니다. 플러그인만 설치했다고 앱이나 훅이 설치되는 것은 아닙니다.

## 이미 설치했을 때

다음에는 **AutoPets 켜줘**. 현재 설정을 유지하고 필요한 연결 도구만 복구합니다. 새 버전은 앱의 업데이트 확인을 통해 별도로 선택합니다. 새 설치 링크를 누를 때마다 자동 업그레이드하지 않습니다.

현재 UI 제작 펫의 제작 기본값은 가볍게이며 실제 모델 적용과 구분합니다. 명시적으로 맡긴 하위 작업의 실행 기록을 확인하고 부모 채팅 모델은 유지합니다. 모든 입력의 자동 모델 변경·제출 보호는 현재 지원하지 않습니다. Windows 로그인 자동 실행은 기본 꺼짐입니다.

## 끄기·제거

- 펫 메뉴에서 이번 작업 도움 끄기·숨기기·AutoPets 종료를 선택합니다.
- 종료 후 훅이 앱을 다시 켜지 않습니다.
- 앱의 연결 해제는 AutoPets 소유 훅과 변경되지 않은 설치 스킬만 제거합니다. 다른 훅과 사용자 제작 스킬은 보존합니다.
- 연결 해제 후 Windows의 설치된 앱에서 제거합니다. 작업 기록 삭제는 설정창에서 별도로 선택합니다.

## 검토용 패키지

Windows CI의 설치 EXE는 공개 서명 버전이 아닙니다. 기존 `AutoPets-windows-x64.zip`은 이전 개발·검수 경로의 호환용이며 초심자용 대표 설치 경로가 아닙니다. `AutoPets-plugin-review.zip`도 디렉터리에 등록되지 않은 검토용 스킬 패키지입니다.

사용자 데이터는 기존 `local.autopets.desktop` 위치, 연결 도구와 설치 기록은 `%LOCALAPPDATA%/AutoPets`를 유지합니다. 보안 정책이나 Codex 훅 신뢰를 우회하지 않습니다.
