# AutoPets 시작하기

**목표: Codex에 설치 링크 한 줄을 보내면 설치부터 펫 실행까지.**

현재는 검토용 패키지 단계입니다. 공개 Release와 실제 Codex 신뢰·새 채팅 전달 검증은 아직 완료되지 않았습니다. 지금 이 문서만으로 공개 설치가 가능하다고 안내하지 않습니다.

## 배포 후 사용할 요청

> 이 링크의 AutoPets 설치하고 켜줘.

다음부터는 **AutoPets 켜줘**. 처음에는 균형 있게 시작하며, 펫에서 바꿀 수 있습니다. Windows 로그인 자동 실행은 꺼져 있습니다.

## 요청을 받은 Codex의 처리

1. 설치 기록이 있고 연결 도구가 정상이라면 기존 설치의 Node와 시작 도구를 실행합니다. 이때 배포 파일을 다시 다운로드하지 않습니다.
2. 첫 설치라면 이 문서와 같은 릴리스의 채널 정보에서 **고정 버전 URL·ZIP SHA-256·지원 환경 검증**을 확인합니다. 공개 버전이 비어 있으면 중단하고 공개 전이라고 설명합니다. 임의 최신 커밋이나 만료되는 Actions artifact를 공개 배포로 대신하지 않습니다.
3. Windows x64 로컬 환경에서 ZIP을 내려받아 안내된 SHA-256과 비교합니다. 안전한 임시 폴더에 압축을 풀고 경로가 폴더 밖으로 나가지 않는지 확인합니다. 원격 코드 문자열을 바로 실행하지 않습니다.
4. 검증한 패키지의 `install.ps1`을 현재 작업 디렉터리와 `CODEX_THREAD_ID`를 유지해 실행합니다. 기존 실행 정책이 허용하지 않으면 우회하지 않고 해당 단계가 필요하다고 설명합니다.
5. 정상 훅 신뢰 확인이 필요하면 Codex의 검토 화면을 안내합니다. 이미 허용된 범위는 다시 묻지 않습니다. 작업을 자동 재전송하지 않습니다.
6. 결과의 앱 준비·채팅 연결·자동 도움 전달·보호 확인을 구분합니다. 실제 지원이 확인되지 않은 모델 변경이나 절감 효과는 주장하지 않습니다.

## 검토용 패키지

Windows CI의 `AutoPets-windows-x64.zip`은 앱 설치 파일, Node 24, LICENSE, 연결 모듈, 시작 도구, 파일별 해시를 포함합니다. 소스 체크아웃이나 개발 도구가 필요 없습니다. 검토용 패키지의 파일 무결성 확인은 배포자 서명·Windows 실행 허용·실제 Codex 검증을 대체하지 않습니다.

사용자 데이터는 기존 `local.autopets.desktop` 위치에 유지합니다. 연결 도구와 설치 기록은 `%LOCALAPPDATA%/AutoPets`, 스킬과 사용자 훅은 해당 Codex 프로필에 둡니다. 다른 훅과 사용자 제작 스킬을 덮어쓰지 않습니다.

## 복구·종료·연결 제거

- 다시 부르면 정상 파일은 재사용합니다. 누락·변경된 도구는 같은 버전 패키지로 복구합니다. 다른 버전은 자동 적용하지 않습니다.
- 펫 메뉴에서 숨기기·종료를 선택할 수 있습니다. 종료 후 훅이 앱을 다시 켜지 않습니다.
- 연결 해제를 요청하면 설치된 시작 도구의 `--disconnect`를 실행합니다. AutoPets 소유 훅과 변경되지 않은 설치 스킬만 제거하고 작업 기록은 유지합니다.
- 앱 자체는 Windows의 설치된 앱에서 제거합니다. 연결 해제를 먼저 수행합니다. 기록 삭제는 앱 설정에서 별도로 선택합니다.
