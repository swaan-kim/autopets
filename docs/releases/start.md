# AutoPets 설치와 시작

**설치 → Codex에 펫 준비 → 쓰던 채팅에서 펫 부르기.**

[AI에게 설치 부탁하기·설치 절차](../../INSTALL.md) · [GitHub 개발 미리보기](https://github.com/swaan-kim/autopets/releases) · [배포 식별 정보](https://github.com/swaan-kim/autopets/blob/main/docs/releases/preview.json)

현재는 **미서명 개발 미리보기**입니다. Windows x64의 로컬 Codex를 대상으로 하며, PC의 보안 정책에 따라 차단될 수 있습니다. 보안 설정을 바꾸지 않습니다. 서명된 안정판과 자동 업데이트는 아직 활성화하지 않았습니다.

## 직접 설치하기

1. [Releases](https://github.com/swaan-kim/autopets/releases)에서 **Pre-release**의 제한과 소스·검사 결과를 확인합니다.
2. 같은 배포의 `preview.json`과 설치 EXE를 받습니다. 설치기의 이름과 SHA-256은 해당 manifest를 기준으로 확인합니다. 소스 ZIP은 설치 파일이 아닙니다.
3. 미서명 시험판임을 이해하고 설치를 선택한 경우에만 진행합니다. Windows가 차단하면 멈춥니다. 보호 설정 해제나 차단 우회는 설치 방법에 포함하지 않습니다.
4. 앱에서 펫을 고르고 **Codex에 펫 준비**를 누릅니다. 설치 프로그램 자체는 Codex의 신뢰를 승인하지 않습니다.
5. 사용할 Codex 채팅에서 **AutoPets 스킬**로 펫을 부릅니다. 새 스킬이 보이지 않으면 Codex의 스킬 목록을 새로 고치거나 진행 중인 응답이 끝난 뒤 앱을 다시 엽니다.

앱과 실행 런타임·연결 도구가 설치 EXE에 포함됩니다. 일반 사용자에게 Git·Node·Rust나 콘솔 입력을 요구하지 않습니다. 현재 채팅에 연결하려면 Windows 로컬 Codex 로그인과 하위 작업의 모델·추론 지정 기능이 필요합니다. 호스트에서 사용할 수 없는 설정은 임의로 대체하지 않습니다.

## 채팅에서 쓰기

기본 웹페이지 펫은 `AutoPets 스킬로 UI 제작 펫 연결해줘`로 시작합니다. 연결 후 `제작 펫으로 행사 페이지 계획만 세워줘`, 계획 확인 후 `그대로 구현해줘`라고 요청합니다. 자연어 호출이 되지 않으면 AutoPets 스킬을 직접 선택합니다.

앱에서 저장한 특정 펫은 **시작 요청 복사**로 정확한 ID·개정을 전달합니다. 연결 후에는 같은 채팅에서 설정을 재사용합니다. 짧은 호출로 앱의 선택을 자동으로 가져오는 기능은 아직 제공하지 않습니다.

**앱 실행 / Codex 준비 / 채팅 연결 / 실제 결과**는 서로 다른 상태입니다. 복사만으로 연결되지 않으며, OS에 채팅 열기를 요청한 것만으로 도착이나 실행을 확인하지 않습니다.

## 기존 설치와 종료

- 이미 설치돼 있다면 먼저 기존 앱을 확인합니다. 정상 설치를 불필요하게 다시 받지 않습니다.
- 다른 버전으로 업데이트할 때는 사용자의 명시적 업데이트 요청을 확인합니다. 앱의 **종료**를 사용하고 기존 설정·기록을 보존합니다. 자동 업데이트는 비활성입니다.
- 펫 숨김, 도움 끄기, 앱 종료는 서로 다른 동작입니다. 도움을 끄면 새 펫 작업을 실행하지 않습니다.
- 제거가 필요하면 앱의 연결 해제 후 Windows 설치된 앱에서 제거합니다. 사용자 기록 삭제는 별도 선택입니다.

AI용 설치 절차와 확인 명령은 [INSTALL.md](../../INSTALL.md)에 모았습니다. 미리보기는 고정 배포의 `preview.json`과 `install-preview.ps1`을 사용합니다. [안정판 채널](channel.json)의 `publicRelease`는 아직 `null`이며, `releases/latest/download`를 미리보기 설치 주소로 사용하지 않습니다.
