# 독립 개발 인계 — AutoPets

## 제품 계약
기존 AI 채팅에서 평소처럼 요청한다. 펫은 필요한 준비, 현재 채팅 조건 유지, 결과 점검을 돕는다. 설정을 모르는 초심자는 기본값, 숙련자는 상세 설정을 사용한다. 품질을 충족한 뒤 시간과 사용량을 줄인다. 절감 효과는 아직 미측정이다.

현재 단계는 소스·격리 검수다. 앱 설치, 훅 신뢰 설정, 계정 조작, 실제 채팅 입력, 공개 배포는 포함하지 않는다. 실제 연결·모델 변경·효과를 fixture 성공으로 선언하지 않는다.

## 공통 작업 지시문
각 담당 작업에 아래 공통 문구와 해당 역할을 함께 전달한다.

> AGENTS.md와 docs/roadmap/implementation.md를 읽고 지정 범위만 구현하세요. 시작 시 현재 브랜치·변경 파일·선행 계약을 확인하세요. 다른 담당자의 파일을 덮어쓰지 마세요. 공통 타입 변경은 먼저 통합 담당자에게 필드·기본값·이관·검사 사례를 제안하세요. 현재 사용자 요청이 저장 선호보다 우선합니다. 채팅 데이터 격리, 지원 여부의 정직한 표시, 원래 작업을 막지 않는 실패 처리를 유지하세요. 완료 시 변경 파일, 수행 검사, 실제 연결 검증 여부, 남은 문제를 전달하세요. 설치·신뢰 변경·새 유료 API·실행 중 이미지 생성·반복 모델 호출은 하지 마세요.

동시에 수정할 때에는 역할별 파일 소유권을 먼저 정한다. 별도 작업 디렉터리에서 개발하는 경우 통합 담당자가 공통 계약을 먼저 반영하고 순서대로 합친다. 구조 정리는 하나의 체크아웃에서 화면·Rust·연결 파일 소유권을 나누고 통합 담당자가 워크스페이스·CI·문서를 처리한다.

## 역할별 다음 요청

### 00 통합
계약 변경을 검토하고 각 역할의 산출물을 순서대로 통합하세요. 기본값 이관, UI fixture, Node 검사, Windows CI를 확인하세요. 실제 연결·서명·사용자 테스트는 별도 미검증 항목으로 남기세요.

### 01 UX
작은 펫 카드는 작업명, 현재 도움 한 문장, 중요 조건, 작업 방식, 상세 버튼으로 제한하세요. 숨김/도움 끄기/종료는 직접 접근할 수 있게 하세요. 상세는 현재 작업·기본 설정·연결/데이터의 3탭입니다. 설정 저장과 전달 확인을 섞지 마세요. 작은 화면·키보드·오류·빈 상태까지 검수하세요.

### 02 작업 규칙
요약/수정은 바로 처리하고 조사·문서·복합 기획에 필요한 절차만 붙이세요. 불확실하면 일반 처리로 남기세요. 명시적 요청, 작업별 설정, 공통 기본값 순으로 우선합니다. 코드 검사와 모델 자체 점검을 구분하고 사실 정확성 통과를 지어내지 마세요.

### 03 저장·앱
선호와 작업별 override를 분리하고 revision으로 동시 수정을 보호하세요. 조건 수정 전 스냅샷은 한 단계만 보관하고 삭제 시 함께 제거하세요. 앱 재시작·오래된 요청·도움 끄기·개별 펫 숨김을 검수하세요. 네이티브 배율/다중 모니터 검사는 실제 PC 증거가 필요합니다.

### 04 Codex
기존 준비 훅에서 변경된 짧은 지침만 전달하고 기록 일부가 빠지면 알리세요. 관측 훅은 메타데이터만 받습니다. stdout 생성과 모델 전달 확인은 다른 상태입니다. 실제 연결 검수 승인이 생긴 후에만 두 채팅·재개·압축 복구를 확인하세요.

### 05 ChatGPT
기존 채팅을 보존하는 연결부를 독립적으로 검증하세요. 계정/채팅 식별이 불명확하면 변경하지 마세요. 한국어 입력·첨부·수정·재전송·다중 탭 회귀를 준비하세요. 검증 전 UI 모델 선택과 자동 라우팅은 활성화하지 마세요.

### 06 시각 경험
기존 크림색 픽셀 펫과 18프레임을 재사용하세요. 조사·작성·도구는 관측 행위, 어지러움은 확인 필요, 화남은 오류, 기쁨은 응답 도착입니다. 고민 모션은 근거가 있는 상태에만 연결하세요. 모든 문구는 짧게, 상세 이유는 펼쳐보기로 둡니다.

### 07 QA
자동 도움 오류가 본래 채팅을 막지 않는지 검수하세요. 단위 검사, 브라우저 fixture, Windows 빌드, 실제 연결, 사용자 효과를 나눠 보고하세요. 사용자 테스트는 초심자 3명/숙련자 2명의 요청·조절·끄기와 수고 감소 이해를 확인하는 자료까지만 준비하세요.
