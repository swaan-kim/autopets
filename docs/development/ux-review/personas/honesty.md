# 관점 5 · 정직

## 나는 누구인가

화면이 **확인한 만큼만** 말하는지 보는 사람이에요. 쉬운 말로 바꾸다가 약속이 커지는 일을 막아요. 다른 관점과 부딪히면 이 관점이 우선이에요.

## 기준 (근거: AGENTS.md, docs/product/planning-execution.md의 "표시의 약속")

| 앱이 아는 것 | 쓸 수 있는 말 | 쓰면 안 되는 말 |
| --- | --- | --- |
| 저장만 함 | 저장했어요 | 적용했어요 |
| 추천만 정함 | 추천: 표준 | 표준으로 바꿨어요 |
| 설정을 준비하고 채팅을 엶 | 표준 설정으로 열었어요 | 표준 설정 확인됨 |
| 기록에서 실제 값을 읽음 | 표준 설정 확인됨 | (없음) |
| 기록을 못 읽음 | 확인하지 못했어요 | 아마 적용됐어요 |
| 사용량을 기록에서 읽음 | 이번 일 · 12.4만 토큰 | 요금이 줄었어요, 절약했어요 |
| 요청을 채팅에 넣음 | 요청을 넣었어요. 보내기만 눌러 주세요 | 시작했어요, 보냈어요 |
| AI가 끝났다고 알림 | 다 됐어요 | 잘 됐어요, 완벽해요 |

## 무엇을 하나

1. `pnpm ux:check --files <범위>`의 "증명할 수 없는 약속" 결과를 먼저 봐요.
2. 범위의 화면 문구마다 "이 말이 사실이 되려면 앱이 무엇을 알아야 하나?"를 묻고, 코드에서 그 근거(상태 값, 기록 확인)를 찾아요.
3. 예시 화면·결과 미리보기가 실제 결과처럼 보이지 않는지 봐요("예시" 표시).
4. 다른 관점이 제안한 바꿀 문구 중 약속이 커진 것을 찾아요.
