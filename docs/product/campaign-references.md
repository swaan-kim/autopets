# 펫·스킬 서비스에서 가져올 원칙

2026-10-19 공식 페이지 재조회. **즉시 반응 → 실제 도움 → 쉬운 재사용**을 AutoPets에서 시험한다. 아래 제품의 인기가 특정 기능 때문에 생겼다는 인과관계나 AutoPets의 동일한 효과는 확인되지 않았다. [첫 타겟과 검증 기준](campaign-target.md).

## 관찰한 사실과 제품 가설

| 레퍼런스·1차 출처 | 공식 페이지에서 확인한 사실 | AutoPets에 적용할 가설 | 이번에 가져오지 않을 것 |

| [Spirit City · Steam](https://store.steampowered.com/app/2113850/Spirit_City_Lofi_Sessions/) | 유료 본편·선택 확장 콘텐츠. 동료와 공간 꾸미기에 할 일·집중 타이머·습관 기록을 결합한다 | 펫이 실제 작업 단계와 함께 행동하면 작업에 곁들이는 이유가 생길 수 있다. 전환 때 또렷하게, 집중 중에는 조용하게 반응한다 | 별도 집중 도구 묶음·공간 꾸미기·경험치, 실시간 3D 엔진 |
| [Finch · 공식 소개](https://finchcare.com/about-finch) | 핵심 기능 무료·선택 Finch Plus 구독. 작은 목표 수행을 펫의 모험·성장과 연결한다 | 계획 확인과 결과 확인처럼 작은 진전을 함께 경험하게 한다. 완료는 실제 기록에 연결하고 한 번 반응한 뒤 쉰다 | 돌봄 의무·연속 출석 압박, 정신건강 개선 효과의 차용 |

| [Skills.sh · 공식 문서](https://www.skills.sh/docs) | CLI 설치 집계로 순위를 구성하며 GitHub 소스·팩·감사 안내를 제공한다. 모든 스킬의 품질·보안을 보장하지 않는다고 밝힌다 | 결과 예시로 선택하고 정확한 출처·버전·수정 여부를 확인한다. 인기·감사·AutoPets 실제 작동 증거를 분리한다 | 인기 순위를 결과 품질 점수로 바꾸기, 감사됨을 안전 보장으로 표시 |
| [Claude · 공식 통합 디렉터리 안내](https://support.claude.com/en/articles/14328846-browse-skills-connectors-and-plugins-in-one-directory) | 호스트의 Customize에서 스킬·연결·플러그인을 찾아 추가하고 관리한다 | 스킬 카탈로그 접근만으로는 외부 앱의 추가 부담을 정당화하기 어렵다. 작업 재개·준비 재사용·동반 경험을 대안과 비교한다 | 호스트 안에서 이미 가능한 기능을 AutoPets만의 기능처럼 설명, 계정·신뢰 절차 대신 승인 |

표의 ‘적용할 가설’과 ‘가져오지 않을 것’은 AutoPets의 제품 판단이다. 원본 서비스의 권장 사항이나 성공 원인이라는 뜻이 아니다. 디자인 구조만 참고하며 캐릭터·로고·스크린샷의 재배포 권한을 확보했다고 간주하지 않는다.

## 사용 규모의 간접 지표

| 기준 | 2026-10-19 관찰 | 해석 한계 |
| --- | --- | --- |
| Bongo Cat Steam 영문 리뷰 | **30,471개 · 긍정 96%** | 영문 리뷰 수이며 설치·유료 구매·전체 사용자 수가 아님 |
| Spirit City Steam 영문 리뷰 | **9,154개 · 긍정 97%** | 승인 계획의 이전 스냅샷 9,153개에서 재조회 시 1개 증가. 매출·사용 지속성의 증거가 아님 |
| [Finch 미국 App Store](https://apps.apple.com/us/app/finch-self-care-pet/id1528595748) | **765K 평점 · 4.9/5** | 미국 상점의 반올림 표기. 리뷰 수·고유 사용자 수·효과 크기가 아님 |
| Raycast·Skills.sh·Claude 디렉터리 | 위 문서에서 기능 구조 확인 | 이 비교에서 활성 사용자·매출 수치를 검증하지 않았으며 같은 규모 순위로 비교하지 않음 |

숫자는 확인 날짜·지역·언어·집계 종류와 함께 보존한다. 앱의 품질·속도·절감률 홍보에는 사용하지 않는다. Before/After는 같은 과제와 조건의 자료를 확보한 뒤에만 비교로 제시한다.

## 네 장면에 적용할 설계 기준

| 장면 | 화면에서 먼저 볼 것 | 관찰할 행동 |
| --- | --- | --- |
| 처음 맡기기 | 요청·결과 예시·짧은 스킬 출처·주 행동 하나 | 모델 설명 없이 무엇을 맡길지와 결과를 예측하는가 |
| 여러 작업 사이 복귀 | 알아볼 작업명·상태·다음 행동 | 확인 필요한 A/B 중 맞는 기존 채팅으로 돌아가는가 |
| 지난 방식으로 새 일 | 재사용할 구성·빈 새 요청 | 이전 내용·승인과 설정을 혼동하지 않는가 |
| 결과 확인 | 실제 결과로 가는 행동·새 일 시작 | 호감 평가와 별개로 자기 업무를 다시 맡기는가 |

기존 [설치·대표 실행 근거](../testing/installed-core-20261012.md)는 기능 연결의 증거이고, [새 홈의 브라우저 검사](../testing/pet-home-20261017.md)는 화면 동작의 증거다. 두 기록이 타겟 사용자 편익을 입증하지는 않는다. 사용자 검사 **0/5**, 실제 AI **71/72턴** 상태에서 먼저 AI 없는 관찰을 준비한다. 출시 준비·유료화·역할 확장은 이 비교표만으로 통과시키지 않는다.
