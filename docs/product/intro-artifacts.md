# 한 장 소개 자료를 완성해주는 펫

**설정을 몰라도, 한국어 기획·제품 설명을 공유할 수 있는 한 장으로 정리하기 쉽게 합니다.**

이번 개발 브랜치의 첫 전문 업무입니다. 제품 소개·기획 요약·비교 설명 세 양식과 고정된 baoyu-infographic 자료를 사용합니다. 모델 설정은 펫의 업무 정체성과 분리하며 기존 상세 설정을 유지합니다.

## 사용 흐름

**예시 보기 → 현재 작업 선택 → 제작 조건 저장 → 기존 AI에서 PNG 제작 → 초안 확인·수정 → 다운로드 → 스타일 재사용**

| 화면에서 하는 일 | 구현 범위 |
|---|---|
| 예시와 양식 선택 | 제품 소개·기획 요약·비교 설명의 구조 예시. 실제 생성 결과와 구분 |
| 준비 내용 확인 | 대상·핵심 메시지·요점·필요한 원문 발췌·출처·스타일 저장 |
| 기존 채팅에 요청 | 3KB 이하 요청 복사, 원문 포함 준비 내용 별도 복사. 복사는 지침 전달 완료가 아님 |
| 실제 PNG 등록 | PNG와 이미지에 보이는 문구를 함께 등록. 파일 경로 대신 관리 저장소에 사본 보관 |
| 검수 | PNG 디코딩·용량, 제공 문구의 항목·숫자 검사. 가독성·배치·원문 충실도는 사람이 확인 |
| 부분 수정 | 글 줄이기·핵심 강조·구성 바꾸기·자유 수정. 기준 버전·수정 요청·이전 PNG 보존 |
| 결과 확인 | 생성됨·검사됨·사용자 확인됨을 구분. 파일 다운로드는 사용자 채택 전에도 가능 |
| 내 스타일 | 사용자가 확인한 버전의 색상·로고·양식·문구 길이만 저장·수정·삭제. 다른 채팅의 업무 내용은 제외 |

원문은 사용자가 선택했거나 확인한 자료만 저장합니다. 전체 대화를 수집하지 않습니다. 요청에 있는 정보를 기존 실행 모델이 정리하도록 선택형 스킬에 지침을 추가했으며, 별도 분류·요약 모델은 호출하지 않습니다.

## 현재 작동 범위

- **로컬 구현:** 새 소개 자료 화면, 채팅별 상태, 버전·검수·스타일 저장, 다운로드, 현재 작업용 CLI.
- **격리 검증 대상:** 앱 명령과 HTTP 계약·인증, 두 채팅 분리, 잘못된 PNG·개정 충돌, 스타일 재사용, 화면 사용 흐름.
- **실환경 미검증:** 기존 Codex 창에서 지침·생성 파일이 전 과정 전달되는지. 스킬은 자동 등록하지 않았습니다.
- **자동화하지 않음:** AutoPets에서 생성 버튼을 누르는 즉시 기존 채팅에 제출, 모델 변경, 상위 모델 승격, 자동 재생성, 사용자 검수 대행.

자료 생성은 사용자가 요청했을 때 기존 AI가 제공하는 이미지 도구로 수행합니다. 앱 자체의 생성 API는 없습니다. 도구가 없는 환경에서는 제작 요청을 준비하고 미지원 상태를 알립니다. 현재 앱에 실제로 관측된 Codex 작업이 없으면 연결을 안내하며 가짜 작업을 생성하지 않습니다. 브라우저 미리보기는 저장·실행을 하지 않습니다.

## 출처와 검수의 한계

[baoyu-infographic 원본](https://github.com/JimLiu/baoyu-skills/tree/1567581c26ec29f4216c6e6835415bf30343b0e3/skills/baoyu-infographic), 버전 `1.117.4`, MIT. 고정 커밋과 개별 파일 해시는 [출처 기록](../../packages/guidance/baoyu-source.json)에 있습니다. [원본 라이선스](../../packages/guidance/vendor/baoyu-infographic/LICENSE)를 포함합니다. AutoPets 지침은 이 사본의 레이아웃·스타일 참고를 사용하되 별도 유료 생성 API·전역 설정·설치 절차를 실행하지 않습니다.

등록된 `renderedText`는 실제 PNG를 확인한 사용자가 제공하는 문구입니다. OCR로 이미지와 대조한 결과가 아닙니다. 원문에 없는 숫자는 경고하고, 바꿔 쓴 문장은 사람이 원문 충실도를 확인합니다. 숫자 존재 검사는 사실성·출처 정확성 검증이 아닙니다. 한국어 효과·품질·토큰 절감은 아직 측정하지 않았습니다.

[SkillsBench 1.1](https://arxiv.org/html/2602.12670v4)은 평균 평가점수 33.9%→50.5%를 보고했지만 동일 내용을 잘 쓴 프롬프트로 제공한 조건과 비교하지 않았습니다. [SWE-Skills-Bench](https://arxiv.org/html/2603.15401v1)는 개발 과제에서 49개 중 39개 스킬의 성공률 개선이 없고 평균 토큰은 10.5% 증가했다고 보고합니다. 이 연구를 한국어 비개발자의 만족도나 AutoPets 절감률로 해석하지 않습니다.

## 다음 확인

1. 실제 Windows Codex 두 채팅에서 준비 → 생성 파일 등록 → 수정 → 다운로드를 확인합니다.
2. [한국어 평가](../testing/intro-evaluation.md)로 스킬 효과와 AutoPets의 조작 편의성을 따로 측정합니다.
3. 초심자 3명·숙련자 2명 중 4명이 도움 없이 흐름을 끝내고, 품질을 유지하면서 수고가 줄어드는지 확인합니다.

이번 구현에는 실제 연결 활성화·설치·참가자 모집·공개 배포가 포함되지 않습니다. PPT 편집, 여러 AI의 자동 연결, 자동 모델 승격도 후속 범위입니다.
