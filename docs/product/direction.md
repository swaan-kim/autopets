AI 설정을 몰라도, 매번 고르기 귀찮아도. 필요한 품질로 일을 끝내도록 돕는다.

유료 AI를 기본값으로 쓰는 비전공 초심자와, 모델·프롬프트·작업 방식을 반복 설정하는 숙련자를 대상으로 한다. 처음 한 번 연결 → 기존 AI 채팅창에서 요청 → 자동 준비·실행 보조 → 결과 점검. 별도 채팅 앱은 만들지 않는다.

## 기본값

- 최초 동의 전 자동 도움 꺼짐. 추천 설정은 자동 / 허용 범위에서 자동 / 더 높은 사용 수준 허용 안 함.
- 목표는 품질 기준 충족 후 절약. 모호하거나 미평가된 작업은 서비스의 기존 모델·자동 선택을 유지한다.
- 작업 방식은 자동·빠르게·꼼꼼하게. 실제 Plan 모드·실행 권한 변경과 다르다.
- 초심자는 추천 설정 하나, 숙련자는 상세 모델 고정·허용 범위를 사용한다. 미검증 연결에서는 설정만 저장하고 실제 적용으로 표시하지 않는다.
- 펫은 작업명과 한 문장만. 클릭하면 작은 작업 카드, 상세 선택 시 전용 설정창, 메뉴에는 채팅 도움 끄기·숨기기·종료를 제공한다.
- 기록은 목표·형식·조건·결정·남은 일뿐이며 채팅별로 분리한다. 공통 선호만 재사용하고, 최신 사용자 요청을 우선한다.
- 자동 도움 끄기와 기록 삭제는 별개다. 원래 AI 서비스의 대화는 삭제하지 않는다.

## 부담과 지원

별도 판단·요약 모델, 주기적 코칭, 실행 중 이미지 생성, Jev, 별도 과금 API를 도입하지 않는다. 지침은 UTF-8 3KB 이내이고 변경 없는 지침은 재주입하지 않는다. 간단한 요청에 긴 계획·검색·재검토를 강제하지 않는다.

첫 실증 대상은 Windows Chrome의 ChatGPT 웹과 Windows 로컬 Codex다. 현재 구현은 모두 실제 자동 적용 미검증이다. 모델 라우팅 함수·형식 점검 함수가 있다는 것이 서비스 화면을 제어한다는 뜻은 아니다. 미지원 기능은 추천/검증 필요로 구분한다.

모델·추론 수준 변경은 지원 여부와 실제 적용 증거가 있을 때만 활성화하며 실행 중인 응답을 끊지 않는다. 개별 사용자 요청·모델 고정이 자동 정책보다 우선한다. 도구 사용과 외부 작업 권한은 기존 서비스의 규칙을 유지한다.

효과는 쓸 만한 결과까지의 총사용량·시간·설정 조작·재작업으로 측정한다. 토큰 감소를 유료 구독 요금 절감으로 표현하지 않는다. 품질·절감 효과와 사용자 테스트는 아직 실측하지 않았다.
