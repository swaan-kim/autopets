# AutoPets — AI를 잘 쓰는 방법을 몰라도, 펫과 함께

매번 설정하거나 설명하지 않아도, 내 일을 잘 진행하도록 준비하고 기억해주는 펫.

첫 대상은 기본 AI 설정으로 리서치·문서 업무를 하는 비개발직 실무자다.

| 기능 | 도움 | 편리함 |
| --- | --- | --- |
| 알아서 준비 | 목표·결과 형식·작업 순서 정리 | 긴 프롬프트 준비 감소 |
| 하던 일 기억 | 현재 채팅의 조건·결정·남은 일 유지 | 반복 설명 감소 |
| 내 방식으로 조절 | 빠르게·균형·꼼꼼하게 | 기능 이름 없이 작업 방식 선택 |

처음 한 번 켜기 → 평소처럼 요청 → 준비한 내용 표시 → 진행 확인·간단 조절 → 결과 확인.

자동 도움은 연결이 검증된 환경에서 한 번 켠 뒤 새 채팅에 기본 적용한다. 시작마다 두 질문을 의무적으로 묻지 않는다. 진행에 중요한 모호함만 확인한다. 기본 개입은 시작과 막혔을 때다.

평소에는 펫·작업명·한 문장 상태만 보인다. 클릭하면 지금 돕는 내용, 기억한 조건, 작업 방식, 작업으로 돌아가기를 제공한다. 상세 내역은 접어둔다. 예: “비교 기준을 정리했어요”, “수정한 조건을 기억했어요”.

## 사용자가 정한 기본값

- 한 번 켜면 지원 환경의 새 채팅에 기본 적용; 채팅별 자동 도움 끄기 제공.
- 공통 선호는 명시적으로 선택한 작업 방식·답변 길이·결과 형식만 재사용한다. 기본은 균형 / 간결하게 / 요청에 맞게.
- 업무 목표·조건·결정·남은 일은 해당 채팅 안에서만 유지한다. 원문 전체를 별도로 저장하지 않는다.
- 기록 수정·채팅별 삭제·전체 삭제를 제공한다. 자동 도움 끄기와 저장 기록 삭제는 별개다.
- 실제 모델·Plan 모드는 사용자가 바꾼다. “꼼꼼하게”는 작업 지침이며 실제 모드 전환을 뜻하지 않는다.
- 설정 변경은 다음 메시지부터 반영한다. 적용 대기·전달·기록 저장을 구분한다.
- 펫은 최대 세 개. 추가 채팅은 작업 목록에 두며 사용자가 표시 대상을 교체한다.

## 효과와 범위

설명·설정·상태 확인에 드는 수고를 줄이는 것이 약속이다. 토큰 절감이나 성공률 향상은 검증 전 홍보 수치로 사용하지 않는다. 상태 표시는 실제 이벤트와 저장된 이미지 재생으로 구현한다. 추가 모델을 반복 호출하지 않는다.

Windows 로컬 Codex부터 검증한다. Chat·Work는 공통 안내부터 제공하고 자동 연결은 별도 검증한다. 자동 중단·자동 모델 전환·펫에서 승인·채팅 간 업무 기억 공유는 첫 버전에서 제외한다. Jev는 기본 의존성으로 도입하지 않는다.

이 문서는 목표 제품 정의다. 실제 지원 상태는 [검증 기록](../testing/m1-evidence.md)을 따른다. 기존 공개 소개는 이전 진행 표시 콘셉트이며 새 자동 도움 기능이 구현됐다는 증거가 아니다.
