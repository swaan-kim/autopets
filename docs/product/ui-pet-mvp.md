# UI 제작 펫 — 스킬과 선택 특성이 보이는 MVP

2026-10-01 원플로우 승인 범위. Windows 로컬 Codex의 기존 명시적 펫 호출에 UI 제작 펫 하나와 선택형 Figma 시안 활용을 연결한다. 이전 제작 펫의 실환경 통과는 새 스킬·특성·채팅 복귀의 통과를 뜻하지 않는다.

## 사용자 흐름

1. **이 펫으로 시작**: UI 제작 펫의 역할과 `Anthropic frontend-design 기반` 출처를 확인한다. 작업 방식 상세에서 제작 설정을 바꿀 수 있다.
2. **Codex에 펫 준비**: 펫 호출 스킬을 준비한다. 이미 준비됐다면 **채팅에서 시작하기**로 넘어간다. Figma는 기본 꺼짐이며 설명만으로 기본 웹페이지를 만들 수 있다.
3. **시작 요청 복사**: 저장한 펫 ID와 개정이 포함된 가상 학과 행사 소개 웹페이지 요청을 복사해 사용할 Codex 채팅에 직접 보낸다. 복사 실패 때도 표시된 원문을 직접 선택할 수 있다. 복사는 전송이나 연결 완료가 아니다.
4. 계획을 확인하고 **같은 Codex 채팅**에서 `그대로 구현해줘`라고 요청한다. 앱의 요청 복사 버튼은 전송하거나 계획을 승인하지 않는다.
5. 펫의 **Codex 작업 열기**로 기존 채팅에 돌아가, Codex가 반환한 파일 링크에서 결과를 확인한다. 앱은 실제 실행과 결과 반환을 대조해 상태를 보여준다.

재방문 때는 연결된 펫을 먼저 보여준다. 새 구성을 만들려면 **펫 준비**, 복구·해제는 **연결 설정**, 펫별 도움 끄기와 프로필은 **펫 설정과 관리**를 사용한다. 준비 화면에서 뒤로 이동하거나 연결 도움을 다녀와도 선택은 유지한다. 안내가 전경에 보일 때만 바탕화면 펫을 일시 숨기고, Codex 등 다른 창으로 전환하거나 안내를 닫거나 앱을 숨기면 기존 표시 선호로 돌아간다. 사용자가 숨긴 펫을 임의로 다시 표시하지 않는다.

요청을 복사할 때는 저장소에서 최신 구성을 다시 확인한다. 다른 창에서 설정이 바뀌었다면 **저장한 펫 다시 선택**으로 최신 구성을 확인한 뒤 다시 복사한다. 오래된 요청을 성공 안내와 함께 반복해서 제공하거나 외부 변경을 덮어쓰지 않는다.

계획은 Luna/low로 고정한다. 제작은 가볍게 Luna/low(기본), 표준 Sol/low, 꼼꼼하게 Sol/medium만 제공하며 실행 전에 가용성을 확인한다. 기존 채팅의 저장 설정은 사용자가 새 펫을 선택하기 전까지 유지한다. 부모 채팅 모델 변경, 실제 Plan 강제, 자동 제출과 훅 자동화는 지원 범위가 아니다.

## 기존 채팅으로 복귀

관리 카드와 오버레이는 같은 `open_pet_task(target, expectedRevision)` 명령을 사용한다. 저장된 연결의 출처·전체 채팅 UUID·폴더·개정을 검사하고, [공식 기존 작업 링크](https://learn.chatgpt.com/docs/reference/commands#deep-links)를 OS에 전달한다. 연결 재확인 전이나 도움 꺼짐 상태도 저장 대상이 일치하면 열기를 요청할 수 있다.

표시는 **“Codex에 열기를 요청했어요”**까지다. 전달 성공은 실제 도착·연결 확인이 아니며, 실패 시 전체 작업 ID 복사와 직접 찾기를 제공한다. 새 채팅 생성, 요청 자동 전송, 앱 자체 결과 파일 열기를 대신 실행하지 않는다. 같은 버튼의 중복 클릭과 대상 변경 뒤 늦게 온 결과는 무시한다. 복귀 검사에서는 A → B → A의 열린 채팅 ID와 입력 초안 보존을 별도로 대조한다.

- 공식 출처 표시는 제작자에 대한 설명이며 AutoPets의 인증·성능 보장이 아니다.

## Figma 시안 활용

선택적 특성으로 기본값은 꺼짐이다. 켜면 별도의 AutoPets 보조 스킬로 사용자가 지정한 프레임을 읽고 배치·색상·글자·컴포넌트를 구현에 반영한다. 해당 호스트의 공식 Figma 스킬과 도구를 사용하며 기존 프로젝트 구성요소를 우선한다. Figma 파일을 쓰거나 인증 정보를 앱에 보관하지 않는다.

공식 연결 안내: <https://developers.figma.com/docs/figma-mcp-server/remote-server-installation/#codex>.

연결 준비와 시안 읽기 성공, 이번 작업의 사용 확인을 구분한다. 호출 문자열만으로 성공을 표시하지 않는다. 접근 실패나 근거 부족은 해당 항목을 미확인으로 남긴다. 선택 특성은 저장하되 시안 URL·내용은 다른 채팅에 전달되는 펫 설정에 보관하지 않는다.

## 저장과 실행

기존 펫 템플릿과 저장 구조를 재사용한다. 누락된 선택 특성은 꺼짐으로 읽는다. 저장한 펫의 특정 개정을 정확한 explicit 채팅 대상에 적용하며, 실행 중·미확인 작업에서는 변경을 거절한다. 새 요청에는 선택한 스킬·특성·설정 개정을 고정한다. 설정 변경 뒤 이전 계획 확인을 재사용하지 않는다.

기존 API 요청과 구형 DB를 보존한다. 로컬 실행 증거는 해당 자식·턴에 한정하고 전체 대화와 Figma 원문을 앱 DB에 복사하지 않는다. 호스트 로그 형식에 의존하는 확인은 버전별 조건부 지원이다.
