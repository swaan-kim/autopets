# UI 제작 펫 — 스킬과 선택 특성이 보이는 MVP

2026-09-30 승인 범위. Windows 로컬 Codex의 기존 명시적 펫 호출에 UI 제작 펫 하나와 선택형 Figma 시안 활용을 연결한다. 이전 제작 펫의 실환경 통과는 새 스킬·특성의 통과를 뜻하지 않는다.

## 사용자 흐름

1. 내 펫에서 UI 제작 펫의 역할, 장점, 한계, 기반 스킬 출처를 확인한다.
2. Figma 시안 활용을 선택한다. 기본 UI 제작은 Figma 없이 가능하다.
3. 연결 도구를 준비하고 펫을 저장한다. 선택한 펫 ID와 개정이 포함된 시작 요청을 복사해 사용할 Codex 채팅에 직접 보낸다. 복사는 전송이나 연결 완료가 아니다.
4. 계획을 확인한다. 같은 채팅에서 명시적으로 구현을 요청해야 제작을 시작한다.
5. Codex가 반환한 파일 링크에서 결과를 확인한다. 앱은 실제 실행과 결과 반환을 대조해 상태를 보여준다.

시험은 계획·구현 모두 가용성이 확인된 Luna/low를 사용한다. 기존 채팅의 저장 설정은 사용자가 새 펫을 선택하기 전까지 유지한다. 부모 채팅 모델 변경, 실제 Plan 강제, 자동 제출과 훅 자동화는 지원 범위가 아니다.

## 기본 스킬

- 출처: Anthropic `frontend-design`.
- 원본: <https://github.com/anthropics/skills/tree/41bbe19d1a1a7eaab5e7bb9050a417e5c6cffc8f/skills/frontend-design>.
- 고정 사본의 `SKILL.md`와 `LICENSE.txt`를 해시와 함께 설치본에 포함한다.
- 장점: 화면 구성과 색상·글자·배치의 시각적 방향을 잡는 지침.
- 한계: 결과는 요청과 모델에 영향을 받는다. 기능·접근성 검사와 실제 사용자 검증을 대신하지 않는다.
- 공식 출처 표시는 제작자에 대한 설명이며 AutoPets의 인증·성능 보장이 아니다.

원문을 역할 지침 필드에 복사하지 않는다. 준비 도구가 선택한 파일·버전·해시를 확인하고 자식에게 그 경로를 전달한다. 파일 존재, 실제 읽기, 요구사항 이행을 구분한다.

## Figma 시안 활용

선택적 특성으로 기본값은 꺼짐이다. 켜면 별도의 AutoPets 보조 스킬로 사용자가 지정한 프레임을 읽고 배치·색상·글자·컴포넌트를 구현에 반영한다. 해당 호스트의 공식 Figma 스킬과 도구를 사용하며 기존 프로젝트 구성요소를 우선한다. Figma 파일을 쓰거나 인증 정보를 앱에 보관하지 않는다.

공식 연결 안내: <https://developers.figma.com/docs/figma-mcp-server/remote-server-installation/#codex>.

연결 준비와 시안 읽기 성공, 이번 작업의 사용 확인을 구분한다. 호출 문자열만으로 성공을 표시하지 않는다. 접근 실패나 근거 부족은 해당 항목을 미확인으로 남긴다. 선택 특성은 저장하되 시안 URL·내용은 다른 채팅에 전달되는 펫 설정에 보관하지 않는다.

## 저장과 실행

기존 펫 템플릿과 저장 구조를 재사용한다. 누락된 선택 특성은 꺼짐으로 읽는다. 저장한 펫의 특정 개정을 정확한 explicit 채팅 대상에 적용하며, 실행 중·미확인 작업에서는 변경을 거절한다. 새 요청에는 선택한 스킬·특성·설정 개정을 고정한다. 설정 변경 뒤 이전 계획 확인을 재사용하지 않는다.

기존 API 요청과 구형 DB를 보존한다. 로컬 실행 증거는 해당 자식·턴에 한정하고 전체 대화와 Figma 원문을 앱 DB에 복사하지 않는다. 호스트 로그 형식에 의존하는 확인은 버전별 조건부 지원이다.

## 검증

- 기본 경로: 가상 학과 행사 소개 웹페이지 한 장의 연결 → 계획 → 제작 → 결과 열기.
- 계획 중 파일 변경 0건, 요청마다 자식 1회, Luna/low 실제 기록 대조.
- 선택한 원본 스킬의 전달·읽기 근거 및 결과물 요구사항 확인.
- Figma 특성 꺼짐/켜짐, 미연결 안내, 실제 시안 읽기와 구현 반영.
- A/B 격리, 도움 끄기, 재시작, 설정 개정 충돌, 이전 요청 중복 방지.
- Node 전체, 화면 빌드·UI, Windows Rust 및 영향받는 설치·보존 검사.

실제 AI 시험은 이전 누계 42에서 최대 55턴까지다. 부모·자식을 모두 센다. 기본/Figma 흐름 8턴, 끄기·복구 2턴, 여유 3턴이다. 개발 검사와 CI는 별도이며 원본 진단·턴 장부는 Git에서 제외한다.

판정은 기본 제작과 Figma 특성을 별도로 기록한다. 외부 조건이나 관측 부족으로 막힌 특성을 전체 성공으로 표시하지 않는다. 현재 PC 외의 공개 배포, Work, 다른 펫, Jev, 공유 사이트로 자동 확장하지 않는다.
