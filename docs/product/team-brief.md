펫 앱·설정·채팅별 기록·계획/실행 규칙·설치 도구를 구현하고 격리된 환경에서 검사했습니다. 실제 AI 자동 연결, 설정 실수 방지, 공개 설치와 사용자 편익은 다음 검증 단계입니다.

**2026-09-23 조사 기준 · [상세 현황·근거](../roadmap/project-status.md) · [저장소 안내](../../README.md)**

## 1. 누구의 어떤 수고를 줄이려는가

AI 설정이 낯선 초심자와 반복 설정이 귀찮은 숙련자가 대상입니다. 쓰던 AI 채팅을 유지하면서 **작업 준비·설정 실수 방지·바뀐 조건 유지**를 펫으로 돕습니다. 반복 설정·설명·재작업 감소는 검증할 편익입니다.

## 2. 지금 어디까지 됐는가

| 구현·검사한 것 | 아직 확인하지 못한 것 |
|---|---|
| 독립 펫, 설정·기록 편집, 준비·점검 규칙 | 실제 AI 자동 연결·지침 반영 |
| 계획→실행 프리셋, 불일치 보호 규칙(PR) | 실제 모델 변경·제출 보호·원클릭 채팅 복귀 |
| 설치·실행·복구 도구와 단일 EXE 흐름(PR) | 서명된 공개 설치·업데이트, 사용자 효과 |

**main은 펫·기본 도움·구조 분리까지, 후속 기능은 [PR #14 → #15 → #16](../roadmap/project-status.md#코드와-검증-기준점)에 있습니다.** 공개 설치판은 없습니다. 과거 PC에서 앱 실행은 확인했지만 최신 전체 흐름의 성공 증거는 아닙니다.

## 4. 어느 AI에서 쓸 수 있는가

**실제 자동 적용 검증을 마친 환경은 0개입니다.** Codex Windows는 훅·진단 코드, ChatGPT Chrome은 확장·로컬 통신 기반이 있습니다. Work·VS Code는 호환성 검증 대상, Claude Code·Antigravity는 후속 후보입니다. [환경별 차이](../roadmap/project-status.md#ai별-지원과-연결-제약)

4. **설치:** 설치 버튼·AI 호출을 어떻게 안내하고 연결·신뢰 단계를 보여줄까?
