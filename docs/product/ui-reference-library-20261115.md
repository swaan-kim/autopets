# AutoPets 화면 참고 자료

2026-11-15 · 작업 #82 · 담당 승완. 펫을 고를 때 결과를 먼저 이해하고, 필요한 도구로 짧게 이동하기 위한 자료입니다. 아래 적용 방향은 관찰을 바탕으로 한 AutoPets의 설계 판단입니다. 타사 화면이 AutoPets의 실제 실행 결과나 사용성 검증을 대신하지는 않습니다.

## 이번 화면에 적용한 것

- 펫 카드와 상세는 같은 결과 예시를 보여줍니다. 문서·계획표·학습 노트·여행 동선처럼 결과의 형태가 먼저 읽히게 하고, 상세에서는 크게 볼 수 있습니다.
- 도구는 22개 분류표 대신 바로 맡길 일이 분명한 8개를 보여줍니다. 이름·짧은 설명·사용하는 서비스·열기 버튼을 같은 위치에 둡니다.
- 분류는 구현 방식보다 사용자 목적에 맞춥니다. `문서·표 / 조사·학습 / 내 자료`입니다. 요금·로그인 조건과 출처는 `이용 조건`에서 확인합니다.
- 사용법 페이지를 여는 항목은 `사용법`으로 표시합니다. 앱 열기, 연결 완료, 설치 완료를 같은 뜻으로 쓰지 않습니다.

## 예시 이미지의 출처와 한계

계획표·학습 노트·여행 동선·홍보 문구·발표자료 구성은 저장소의 SVG/React 원본을 직접 고친 자체 디자인 예시입니다. 제품 사진과 바다 사진은 기존 `prompt-gallery-v1` 제작 이미지를 재사용하고, 웹페이지는 기존 `design-example-v1` 예시를 재사용했습니다. 새 이미지 생성 호출이나 주기적 AI 호출을 추가하지 않았습니다. 여행 이미지는 실제 장소 검증 자료가 아닙니다.

기준은 최신 `origin/main`을 포함한 #78과 #76을 합친 UI 검토 소스입니다. 다른 미병합 PR을 모두 main에 반영했다고 설명하지 않습니다. API·DB·호스트 연결·사용자 데이터·자동 전송 계약은 이번에 바꾸지 않았습니다.
