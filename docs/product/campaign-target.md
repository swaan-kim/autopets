# 반복 준비를 줄이고, 하던 일을 펫과 이어서

2026-10-19 · 타겟 가설 1장. **사용자 관찰 0/5, 실제 AI 71/72턴.** 이 문서는 시장 검증이나 모집 완료 기록이 아니다.

## 누구의 어떤 일을 돕는가

**Windows Codex를 이미 쓰는 비개발 마케팅·운영 담당자**가 행사·캠페인 소개 페이지를 초안 작성 → 수정 → 결과 확인까지 이어서 만드는 경험을 우선한다.

| 구분 | 첫 타겟의 조건 |
| --- | --- |
| 익숙한 것 | 기존 Codex 채팅에 업무를 요청하고 결과를 확인하는 일 |
| 익숙하지 않은 것 | GitHub 스킬 탐색·설치, 긴 역할 지침 작성, 모델·추론 선택 |
| 반복되는 상황 | 두 개 이상의 작업을 오가거나, 비슷한 행사·캠페인을 다시 준비함 |
| 기능적 불편 | 멈춘 위치를 다시 찾고, 지난번에 잘 쓴 지침·설정을 다시 준비함 |
| 감정적 불편 | 대기와 반복 준비가 지루하고 확인할 일이 흩어져 부담스러움 |
| 지금의 대안 | Codex 채팅 기록, 저장한 요청문, 메모, 스킬 직접 선택 |

처음에는 **원하는 결과를 쉽게 시작하는 편의**, 작업 중에는 **현재 상태와 다음 행동**, 다음에는 **마음에 든 방식의 재사용**을 제공한다. 펫은 이 흐름을 알려주는 동료다. 장식의 호감과 업무의 편익을 따로 평가한다.

## 사용자가 이루려는 세 가지

| 사용 상황 | 원하는 행동과 결과 | 확인할 증거 |
| --- | --- | --- |
| 새로운 행사를 준비한다 | 스킬·모델 조사 없이 요청을 준비하고 어떤 결과를 받을지 안다 | 설명 없이 과제·예상 결과·다음 행동을 찾음 |
| 다른 일을 하다 돌아온다 | 확인할 계획이나 결과가 있는 정확한 채팅으로 돌아간다 | A/B 중 올바른 작업 선택, 현재 단계·다음 행동 이해 |
| 비슷한 행사를 다시 맡긴다 | 지난번 설정을 가져오고 새로운 내용만 입력한다 | 새 요청에 이전 내용·승인이 없고 설정 재선택이 불필요함 |

소개 문장은 **“반복 준비는 줄이고, 하던 일은 펫과 이어서.”**로 고정한다. 첫 체험은 가상 행사 소개 페이지이며 외부 서비스 연결을 요구하지 않는다. 사용자가 모델을 알아야 시작할 수 있는 흐름을 만들지 않는다. 출처·버전·실행 근거는 선택 및 상세 화면에서 확인한다.

## 먼저 검증할 가설과 모집 조건

무료 소규모 검사 대상은 **5명**이다. Windows Codex를 이미 사용하고, 최근 한 달 안에 행사·캠페인 제작 또는 수정 경험이 있으며, 다음 유사 업무가 있는 사람을 모집한다. 스킬·프롬프트·모델 설정을 일상적으로 직접 관리하는 전문가보다 해당 준비가 낯선 사람을 우선한다. 모집 후보 채널은 실무 AI·마케팅·운영 커뮤니티이며, 이 문서가 연락·게시를 수행한 것은 아니다.

1. 화면을 보여주기 전에 최근 실제 사례를 듣는다. 반복 준비 또는 작업 재개 불편이 **3/5명**에게 구체적으로 확인되지 않으면 과업을 다시 정한다.
2. AI 없이 첫 이해·전달·작업 재개·설정 재사용을 검사한다. 첫 이해·정확한 재개·설정 재사용은 각각 **4/5명**을 내부 기준으로 삼는다.
3. **4/5명**의 켜두고 싶은 의향과 실제 숨김·방해 행동을 함께 기록한다. 귀여움만으로 유용함을 통과시키지 않는다.
4. 추가 AI 예산과 안전한 배포 조건을 확보한 뒤 실제 결과 비교와 7일 관찰을 한다. **3/5명**의 자기 업무로 자발적인 두 번째 사용을 기준으로 삼는다.

비교 대상은 **같은 스킬·설정의 Codex + 저장된 요청문**이다. 설치·앱 왕복·복사까지 포함한 준비 시간·조작·도움 요청·작업 재개 시간, 결과 품질과 재작업을 기록한다. 진행자가 요청한 재사용은 자발적 재사용에 포함하지 않는다. 작은 표본의 통과를 수요·매출·일반 생산성 효과로 확대하지 않는다.
