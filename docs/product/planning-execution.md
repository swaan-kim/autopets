# 계획은 충분히, 실행은 정해둔 설정으로

AutoPets는 AI 설정이 낯선 초심자와 반복 설정이 번거로운 숙련자가 **원하는 품질로 끝내고, 설정 실수로 사용량을 낭비하지 않게** 돕는다. 별도 채팅 앱이나 유료 API를 만들지 않는다.

## 세 가지 시작 설정

| 선택 | 계획 → 실행 | 이런 일에 |
| --- | --- | --- |
| 가볍게 끝내기 | Sol Medium → Luna Low | 범위가 명확한 정리·반복 작업 |
| 균형 있게 · 추천 후보 | Sol Medium → Terra Medium | 일반적인 문서·조사·구현 |
| 어려운 일 풀기 | Astra High → Astra Medium | 복잡한 설계·분석 |

조합은 평가 후보다. 품질 향상이나 사용량 감소를 보장하지 않는다. 실제 계정에서 확인된 모델과 추론 수준만 적용하며, 연결이 없을 때는 원하는 설정만 저장한다. 기존 사용자는 직접 켜야 하고, 기본값 변경은 진행 중인 다른 채팅을 바꾸지 않는다.

## 한 번에 이해하는 흐름

**설정 선택 → 평소처럼 요청 → 채팅의 계획 확인 → 이대로 진행 → 실행 설정 확인 → 결과 점검**

- 새 업무에는 목표·결과물·조건·완료 기준과 짧은 계획을 준비한다. 짧은 번역·맞춤법·단순 수정은 바로 처리한다.
- 펫은 한 문장만 보여준다. 상세 화면에서 계획→실행 조합, 확인 상태와 변경 이유를 본다.
- 계획을 읽지 못한 연결에서는 계획 요약을 만들어내지 않는다. 사용자가 원래 채팅에서 계획을 확인한다.
- 계획·조건·작업 설정이 바뀌면 이전 실행 확인을 다시 사용하지 않는다.
- 실행 모델을 바꿀 수 없지만 제출 보호가 검증됐다면, 불일치를 발견했을 때 보내기를 보류한다. 사용자는 설정을 바꿔 다시 보내거나 해당 요청 한 번만 현재 설정을 유지한다.
- 설정 확인 실패는 작업을 막지 않는다. `보호 확인 불가`를 표시한다.
- 도움 끄기·펫 숨기기·앱 종료는 바로 선택할 수 있다. 기록 삭제는 별도 조작이다.

## 표시의 약속

| 확인된 것 | 표시할 수 있는 것 |
| --- | --- |
| 로컬 저장만 성공 | 설정 저장됨 |
| 짧은 계획 지침 준비 | 계획 지침 준비됨 |
| 제출에서 모델 확인 | 모델 확인됨 · 추론과 모드는 별도 |
| 실제 설정 변경과 다음 제출 확인 | 해당 항목 적용 확인 |
| 관측 실패·연결 없음 | 보호 확인 불가 |

프롬프트로 실제 Plan 모드나 모델을 바꿨다고 말하지 않는다. 사용량을 모르면 토큰 수·절감률을 추정하지 않는다. 응답 종료는 목표 달성 확정이 아니다.

## 범위

첫 대상은 Windows 로컬 Codex다. ChatGPT는 같은 로컬 설정과 복사 안내를 제공하며, 입력 보조·실제 설정 변경·제출 보호는 각각 별도 검증한다. 이번 변경은 설치·실제 연결 활성화·사용자 모집을 포함하지 않는다.

공식 근거: [모델 선택](https://learn.chatgpt.com/docs/models#choosing-sol-terra-and-luna), [모델·추론·Plan 명령](https://learn.chatgpt.com/docs/reference/slash-commands), [훅의 입력과 제출 보류](https://learn.chatgpt.com/docs/hooks). 문서상 지원과 실제 Windows 연결 증거는 구분한다.
