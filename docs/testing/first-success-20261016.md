# 첫 성공과 두 번째 사용 — 구현·검사 기록

2026-10-16, Windows 로컬 개발 환경. 기준 소스 `96b80ac`와 작업 트리의 화면 변경을 검사했다. 이전 동반 모션 변경과 사용자 미커밋 변경을 보존했다. **실제 AI 시험 추가 0턴, 누계 71/72 유지.**

## 구현한 흐름

1. 첫 화면의 주 행동을 **웹페이지 펫으로 시작**으로 명확히 했다. 기존 실제 결과 예시·예시 체험을 유지하고, 여섯 역할 카드에도 결과 예시와 스킬 출처를 함께 표시했다. 역할과 새 모션은 늘리지 않았다.
2. 자유 입력을 기본으로 두고 **누가 볼지·꼭 알릴 내용**은 선택 항목으로 접었다. 작성한 보충 정보는 저장한 펫 ID·개정을 포함하는 시작 요청에 들어간다. 모델 선택이나 외부 연결을 필수로 요구하지 않는다.
3. **펫 준비 → 요청 복사 → 채팅에 전송 → 접수 확인**을 분리했다. 기존 준비가 확인되면 다시 준비시키지 않으며, 복사 후 기존 Codex 채팅에 직접 보내도록 안내한다.
4. 탭·역할·저장 구성 사이를 이동해도 작성 중인 요청과 복사 안내를 복원한다. 본문·설정 수정 시 이전 복사 상태를 무효화한다. 초안은 **현재 관리 화면 세션의 메모리**에만 두며 앱 종료 후 복원은 이번 범위가 아니다.
5. 확인된 계획에는 **계획 보러 가기**, 완료에는 **결과 보러 가기**를 표시한다. 관리 카드와 오버레이가 기존 대상 ID·폴더·개정 검사와 같은 복귀 명령을 사용한다. 연결이 불명확하거나 도움이 꺼져 있으면 일반적인 **Codex 작업 열기**로 표시한다.
6. 완료 카드의 **같은 펫으로 새 일**은 현재 설정·스킬 참조만 가져오고 요청 입력은 비운다. 현재 설정이 저장 구성과 다르면 복사할 때 새 구성을 저장하며 원래 저장 구성과 A/B 연결은 수정하지 않는다. 이전 작업 내용·계획 승인은 옮기지 않는다.

공개 API·DB·라우팅·설치 식별자 변경은 없다. 자동 전송, 부모 모델 변경, 실제 Plan 모드 강제를 추가하지 않았다.

## 접수와 결과의 증거 범위

- 복사는 전송·연결·실행 성공으로 표시하지 않는다.
- 복사 전에 있던 완료 기록은 새 요청의 접수로 사용하지 않는다.
- 같은 저장 구성의 새 기록이 생겨도 현행 API만으로 사용자가 보낸 전체 요청과 동일한지 확정할 수 없다. **새 기록 · 대조 필요**로 안내하며 접수를 완료 처리하지 않는다.
- OS 링크 전달은 **열기를 요청했음**만 뜻한다. 실제 Codex 도착 확인은 별도 실환경 검사다.
- 브라우저 시험은 합성 상태와 가짜 Tauri 브리지를 사용한다. 실제 채팅·스킬·모델 실행을 재시험한 결과가 아니다.

코드 검토에서 발견한 **다른 역할의 저장 구성을 선택할 때 초안 키가 섞이는 문제**, **같은 역할의 저장 구성 A→B 전환이 A 캐시를 덮는 문제**를 수정하고 브라우저 회귀 검사에 포함했다. 시각 검수에서 발견한 작은 화면의 스킬 출처 열 너비도 수정했다. 이는 개발 검사에서 발견한 결함이며 사용자 5명 관찰 결과로 주장하지 않는다.

전체 UI 검사는 기존 작은 화면·125%/150%에 해당하는 레이아웃 크기·키보드·숨김·동작 줄이기·자산 대체·완료 중복 억제 검사와 새 흐름을 함께 수행한다. 브라우저 크기 변경을 실제 Windows DPI 변경 검증으로 확대하지 않는다. 이번에는 모션 자산이나 반복 실행 루프를 추가하지 않아 CPU·메모리를 다시 측정하지 않았으며 이전 [동반 모션 성능 측정의 범위](companion-20261013.md)를 유지한다.

## 재현

저장소 루트에서 실행한다. 개발 서버가 이미 1420 포트에서 실행 중이면 `pnpm test:ui` 대신 직접 실행기를 사용한다.

```powershell
pnpm test
pnpm build
pnpm test:ui
```

기존 개발 서버 사용 시 전체 UI:

```powershell
$env:AUTOPETS_SCREENSHOT = 'work/first-success-20261016/ui-full.png'
node apps/desktop/tests/ui-smoke.cjs
```

새 흐름만 검사:

```powershell
$env:AUTOPETS_UI_FIRST_SUCCESS_ONLY = '1'
$env:AUTOPETS_SCREENSHOT = 'work/first-success-20261016/first-success.png'
node apps/desktop/tests/ui-smoke.cjs
Remove-Item Env:AUTOPETS_UI_FIRST_SUCCESS_ONLY
```

원본 로그·브라우저 캡처는 Git 제외 `work/first-success-20261016/`에 있다. [화면 비교 자료](../images/first-success-20261016/README.md)는 합성 입력만 포함한다. 제품 화면 변경은 `UiPetStudio`, `PetWorkspace`, `PetExperience`, `TaskPetArt`, `PetTaskReturn`, `ExplicitPet`과 화면 CSS이며, 새 행동 검사는 `apps/desktop/tests/first-success-ui.cjs`에서 재현한다.
