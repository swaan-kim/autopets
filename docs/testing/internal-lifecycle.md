# 종료·데이터 보존 내부 검증

2026-09-25, 설치 기본 작동 검증의 하위 구간. **내부 종료·통신 종료·데이터 재읽기 통과.** 현재 PC에 설치된 AutoPets를 실행·종료하거나 사용자 화면을 조작하지 않았다.

## 검사 방식

`transport::http::lifecycle_tests`는 한글과 공백이 포함된 임시 폴더에 실제 SQLite 저장소를 만들고 임의의 loopback 포트에서 실제 HTTP 서버를 실행한다. 테스트 후 모든 저장소 참조가 해제될 때까지 기다린다. 사용자 데이터·AI 설정·실제 채팅을 사용하지 않는다.

| 검사 | 확인한 증거 | 판정 |
| --- | --- | --- |
| 명시적 종료와 중복 종료 | 연결 파일 삭제, TCP 연결 거절, 서버·타이머의 저장소 참조 해제 | 통과 |
| 핸들 해제 시 자동 정리 | 명시적 종료 없이도 위 정리 조건 충족 | 통과 |
| 대기 중 HTTP 요청 | 요청이 실제 처리에 들어간 뒤 종료. 15초 대기 한도 전에 `forwarded` 응답과 연결 종료, 메모리의 대기 상태 해제 | 통과 |
| 데이터가 있는 저장소 재읽기 | 채팅 2개·이벤트 3개, 이름·완료 기준·알림 설정·펫 배정·문맥·선호 설정 보존, SQLite 무결성, 위치 파일 내용 유지 | 통과 |

대기 요청 검사는 기존 호환 코드의 테스트 전용 승인 설정을 사용한다. 제품의 승인 기능이나 실제 훅을 활성화하지 않는다. 위치 파일 검사는 내용 보존만 확인하며, 창 위치를 실제 복원하는 검사가 아니다.

재시작 후 이전 작업은 실행 중으로 표시되지 않아야 한다. 완료한 작업의 읽지 않음 상태는 보존하고, 이전 실행의 연결 정보는 재사용하지 않는다.

## 실행과 결과

- 로컬 Node 검사: `node scripts/run-tests.mjs` — 160개 통과.
- Windows 전용 실행: [Internal lifecycle checks](https://github.com/swaan-kim/autopets/actions/runs/36105812790).
- 검사 커밋: `871fa987736438c5d992c7387013985aace9ca0f`.
- Windows 검사 결과: 성공. 추가한 검사 4개 통과(2.92초), 전체 Rust 검사 99개 통과(추가 검사 포함, 44.81초), Node 160개 통과.
- Windows job 소요 시간: 준비·컴파일 포함 6분 28초. 설치/앱 시작 시간과는 별도 측정이다.

전용 Windows workflow는 컴파일 자산 준비, Node 검사, 내부 수명주기 검사, Rust 회귀 검사만 수행한다. 설치기를 만들거나 실행하지 않으며 Tauri 앱 창을 생성하지 않는다.

## 판정 범위

이 검사는 내부 종료·통신 종료·저장소 재읽기의 증거다. 실제 앱 종료 버튼, 운영체제 프로세스 종료, 창 재호출, 설치·제거·재설치 검증을 대체하지 않는다. 1번 구간 전체 통과로 표시하지 않으며 다음 구간으로 자동 진행하지 않는다.

검사에서 제품 결함이 재현되지 않아 제품 동작 코드를 수정하지 않았다. 추가한 것은 검사 4개, 테스트 모듈 등록, 설치기를 실행하지 않는 전용 Windows workflow와 이 기록이다. 공개 API·데이터 형식 변경 없음.
