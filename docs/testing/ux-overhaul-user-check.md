# 처음 사용하는 사람의 짧은 확인

자동 UI 검사는 버튼 동작을 확인한다. 아래 확인은 AutoPets를 처음 보는 사람이 직접 해야 하며 자동 검사로 대체하지 않는다.

## 1. 할 일 선택

설명 없이 홈을 보여주고 “오늘 할 일을 정리하고 싶어요”라고 말한다.

- 하루 정리를 찾아 선택하는가?
- 결과가 시간표·체크리스트라는 것을 알아보는가?
- 모델이나 스킬 설명을 펼치지 않고 요청을 적는가?

## 2. 첫 요청

기본 가볍게 설정으로 시작 요청을 복사한다. 이 PC가 준비되지 않았을 때만 Codex 준비가 나타나야 한다.

- 사용할 Codex 채팅에 붙여넣고 보내야 한다는 것을 알아보는가?
- 복사를 실행 완료나 연결 완료로 오해하지 않는가?
- 연결 후 홈에서 정확한 작업을 찾고 결과로 돌아가는가?

## 3. 이어 하기

웹페이지 펫으로 가상 행사 페이지를 계획하고 같은 채팅에서 구현을 요청한다.

- ‘계획 확인 필요’를 결과 완성으로 오해하지 않는가?
- 별도 모델 변경이나 긴 지침 재작성 없이 구현을 이어 가는가?
- 즐겨찾기와 저장 구성을 다시 찾고 본인 초안을 유지하는가?

진행자의 개입 횟수, 길을 잘못 선택한 지점, 완료 여부와 시간을 기록한다. 소수 사용자의 관찰을 일반적인 절감률이나 수요 입증으로 확대하지 않는다. 현재 이 사용자 검사는 미실시다.
