## 범위와 다음 관문

**대표 핵심 흐름은 통과했다.** 저장한 펫 연결 → 준비 지침과 실제 스킬 읽기 → 지정한 하위 작업 모델·강도 → 결과 반환과 펫 상태가 연결된다. 직접 결과 두 역할과 계획 후 제작 한 역할로 확인했다. 설치 앱과 결과 미리보기를 사용할 수 있는 상태로 남겼으며, AI 누계는 **71/72턴**, 예약 0이다. 더 많은 역할의 반복 실행은 사용자의 범위 축소에 따라 하지 않는다.

- 실제로 바꾸는 모델은 **펫에게 맡긴 하위 작업**의 모델·추론이다. 부모 채팅 모델 자동 변경, 실제 Plan 모드 강제, 자동 훅 성공을 뜻하지 않는다.

- 일반 사용자의 이해도·다른 PC·서명된 배포, Work·Dot·Jev는 별도다.
