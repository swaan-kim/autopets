# 일상·업무 작업 펫 6종

## 구현 범위

첫 화면에서 일상 / 업무를 선택하고 할 일을 고른다. 모델 설정은 상세로 접고 기존 채팅에 붙여 넣을 시작 요청을 생성한다. 복사와 실제 연결은 구분한다.

| 분류 | 할 일 | 작업 방법 | 결과 | 확인 방식 |
| --- | --- | --- | --- | --- |
| 일상 | 하루 정리 | AutoPets 자체 제작 | 우선순위·시간표·체크리스트 | 바로 결과 |
| 일상 | 여행 일정 | AutoPets 자체 제작 | 날짜별 동선·준비물 | 바로 결과, 최신 정보 미확인 표시 |
| 일상 | 공부 도우미 | AutoPets 자체 제작 | 쉬운 설명·요약·복습 문제 | 바로 결과 |
| 업무 | 웹페이지 만들기 | 기존 고정 Anthropic frontend-design | 한 장의 웹페이지 | 계획 후 명시적 제작 |
| 업무 | 홍보글 쓰기 | marketingskills/copywriting의 MIT 파생 지침 | 제목·소개문·버튼 문구 | 바로 결과 |
| 업무 | 발표자료 만들기 | frontend-slides의 MIT 파생 지침 | 브라우저 HTML 슬라이드 | 계획 후 명시적 제작 |

외부 스킬 원본 그대로의 제품이 아니다. 홍보글·발표자료 지침은 한국어 입력과 현재 실행 경로에 맞춰 간결하게 수정했다. 원본 커밋·해시·라이선스는 skill-sources.json과 각 스킬에 보존한다. 다른 도구 설치나 원본의 외부 파일 의존성을 자동 실행하지 않는다.

설정표와 메타데이터는 packages/contracts/data/pet-catalog.json에 둔다. 새 RoleId만 추가하고 저장 테이블·앱 식별자·기존 역할을 유지한다. 여섯 펫은 기존 대표 펫 자산을 재사용하며 별도 캐릭터 생성은 하지 않는다. Figma는 웹페이지 펫에서만 선택 가능하다.
