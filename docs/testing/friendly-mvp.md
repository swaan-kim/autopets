- 새 자산의 실패·크기 오류는 기존 자산으로 복원한다. 모두 실패하면 명시적 자리 표시자를 쓴다. 동작 줄이기와 숨겨진 문서에서는 움직임을 멈춘다. 새 자산은 프레임 변경 타이머 없이 CSS를 사용한다.

### 설치된 연결 도구에서 재현한 읽기 표시 누락

계획 시험은 Luna/low 자식 한 번으로 종료됐고 A는 계획 확인 대기, B 설정·요청·파일은 불변이었다. 프로젝트 결과 파일의 추가·수정·삭제는 없었으며 로컬 훅의 복원 메타데이터 한 파일만 갱신됐다. 앱 메시지 도구로 제출했으므로 일반 입력창 성공으로 계산하지 않는다.

자식이 선택된 `frontend-design` 전체 내용을 읽었지만, JavaScript 안에 이스케이프된 Windows 명령 경로와 병렬 호출의 성공 반환 포장을 읽기 감사기가 인식하지 못했다. 명령의 구분자와 제한된 성공 포장 처리만 수정했다. 반환 파일 경로·버전·전체 내용 해시·동일 호출의 유일한 반환 기준은 유지했다. 계획·구현·검토의 실제 기록 모두에서 읽기 증거를 다시 확인했고, 실패 포장·잘못된 경로·잘린 내용·중복 반환은 계속 거부한다. 수정 후 Node **223 통과 / 조건부 1 건너뜀**. 설치본의 표시 복구는 수정본 설치 후 별도 확인한다.

호스트가 위임 입력을 암호화해 기록하는 경우 준비 지침의 생성 시각은 확인할 수 있어도 실제 전달 문자열의 일치는 확인할 수 없다. 이를 전달 실패나 전달 확인으로 단정하지 않고 미확인으로 남긴다. 선택 스킬의 전체 읽기, 계획 응답, 모델·강도 기록은 각각 별도 근거다.

## Dot — 사용자 선택으로 실검사 보류

[공식 PC 연결 문서](https://learn.chatgpt.com/docs/dots/computers-and-apps)와 [작업 문서](https://learn.chatgpt.com/docs/dots/tasks-and-memory)는 연결된 PC의 기존 로컬 Codex 작업 이어가기와 로컬 스킬 사용을 후보 경로로 제공한다. 이것은 AutoPets 연동 검증 결과가 아니다.

현재 자동화 가능한 브라우저의 ChatGPT는 로그인 화면이었다. 사용자가 **Dot 조건만 기록하고 Codex MVP부터 완성**하도록 선택했다. 로그인·PC 접근 허용은 수행하지 않았고 Dot 시험 AI 사용은 0턴이다. Dot 시작 입구나 지원 완료 표시는 앱에 추가하지 않는다.

다음 조건: 사용자가 Dot에 로그인 → 대상 PC를 직접 연결 → PC와 앱이 켜진 상태에서 전용 기존 Codex 작업 지정 → 설치된 AutoPets 스킬로 읽기 작업 하나 → 실제 자식 모델/강도·결과·같은 요청의 펫 상태 대조. Dot 요청 ID와 실행하는 Codex 작업 ID는 분리한다. 공식 연결이 안 되면 화면 조작이나 자체 채팅으로 대체하지 않는다.

## 서명 배포

현재 사용자 인증서 저장소에서 코드 서명 인증서를 발견하지 못했다. CI의 별도 자격 존재 여부까지 증명한 것은 아니다. 미서명 개발 설치본과 보안 정책을 유지한 일반 배포를 분리하며 안정판 채널은 계속 비활성이다. [소유자에게 필요한 서명 준비](../releases/code-signing.md)를 따른다. 개발 화면이나 CI 성공은 이 관문의 통과가 아니다.
