# 두 입구 통합 검수

이번 변경은 코드·검토용 패키지·격리 검수다. 사용자 PC 설치, 신뢰 변경, 공개 릴리스, Store/AI 디렉터리 등록은 하지 않는다.

## 자동 검사

1. `pnpm test`: 설치 잠금·소유 훅·채팅 격리·재호출·복구, public manifest 거절, 공개 전 사이트.
2. `pnpm build` / `pnpm test:ui`: 연결 선택·대기·실패·미지원 호스트·다음 행동·기존 끄기 동작.
3. `pnpm test:rust`: 실제 관측 전 연결 성공 금지, 연결 이후 첫 작업, 종료/재연결, update URL/버전 제한.
4. Windows CI: Node·라이선스·connector·offline WebView2 포함 EXE 생성, 격리 사용자 경로에서 첫 설치·기존 설치 재사용·연결 해제·종료 검수. 로컬 PC에서는 설치 테스트를 실행하지 않는다.
5. `node scripts/build-product-site.mjs --out work/product-site` 및 `node scripts/package-plugin.mjs`: 공개 전 사이트와 미등록 플러그인 패키지.

## 실제 환경에서만 통과시킬 항목

| 영역 | 확인할 증거 | 현재 판정 |
|---|---|---|
| 개발 도구 없는 Windows | 오프라인 WebView2 포함 설치·실행·제거 | CI와 별도 실제 장비 검증 필요 |
| 사용자 경로/재시도 | 한국어·공백, 다운로드 실패·중간 취소·복구 | 자동 fixture + 실제 실행 검증 |
| Codex 두 작업 | 새 작업 ID, 지침 수신, 설정 관측 각각 | 미검증 |
| Work 로컬 / VS Code | 화면·버전별 같은 검사 | 미검증, 지원 승격 금지 |
| Store EXE | 동일 설치 감지, 무인 설치, PE 서명, 업데이트 | 제출 전 별도 검증 |
| 업데이트 | 서명 불일치 거절, 정상 갱신, 기존 데이터·훅 유지 | 공개 서명 버전 전 미검증 |
| 종료 | 종료 후 훅 입력에도 앱이 나타나지 않음 | 격리 검사 + 실제 장비 확인 |
| 개인정보 | 진단에 대화·인증 비밀 없음, 채팅/AI 간 기록 분리 | fixture + 실제 두 채팅 검증 |

## 5명 체험 과제

초심자 3명과 숙련자 2명에게 설명 없이 순서대로 요청한다.

1. 설치 버튼 또는 AI 호출 중 편한 방법으로 시작하기.
2. 사용할 AI를 연결하고 새 업무 한 개 요청하기.
3. 펫에서 현재 도움과 실제 설정 확인 여부 찾기.
4. 현재 작업의 설정 하나 바꾸기, 원래 작업으로 돌아가기.
5. 이번 작업 도움 끄기, 펫 숨기기, 앱 종료하기.

기록: 완료 여부·혼란 지점·설정 조작 수·지원 요청 수·설치와 연결을 구별했는지. 4명이 도움 없이 완료하고 3명이 줄어드는 수고를 말하는지는 탐색 기준이며 효율 입증이 아니다. 모집·발송은 범위 밖이다.

품질·사용량은 기존 한국어 24개 사례에서 계획·지침·실행·재시도를 모두 포함한다. 관측 못한 토큰은 비워 두고 구독 한도와 혼합하지 않는다. [계획/실행 검수](planning-execution.md)
