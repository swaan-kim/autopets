# 복습 도우미 채팅 격리와 화면 검수

[#114](https://github.com/swaan-kim/autopets/pull/114)의 복습 도우미를 최신 main과 발표자료 작업에 통합했다. 복습 알림 비교는 같은 합성 문제 수와 252×404 Windows Chromium 창, 배율 100%다. 문제 묶음 화면은 1280×900과 390px 창에서 확인했다.

- [이전 알림](../changes/133/before-due.png) · [현재 알림](../changes/133/after-due.png) · [작은 창](../changes/133/after-narrow.png) · [문제 묶음](../changes/133/after-batches.png) · [묶음 상세](../changes/133/after-batch.png)
- 합성 UI에서 복습 도우미를 고른 경우에만 복습 표시와 문제 묶음 진입이 나타나고, 목록과 상세에서 돌아갈 수 있는지 확인했다. 다른 채팅에 있는 문제로는 현재 펫에 복습 배지가 생기지 않는다. 묶음을 만들었던 채팅과 폴더, 개정이 맞지 않으면 다른 채팅을 열지 않는다.
- Windows `cargo test --locked`에서 219개가 통과했다. 4개는 기존 설정에 따라 제외됐다. 다른 채팅의 문제 읽기·추가·채점 차단, 다른 채팅의 `$autopets` 호출로 인한 기존 펫 이동 방지, 기존 행 보존과 재시작을 확인했다.
- 복습과 발표자료 스킬을 함께 묶을 때 연결 파일이 앱의 128KiB 내보내기 한도에 맞도록 패키징에서 JSON 들여쓰기를 제거했다. 스킬 원문과 고정 해시는 보존한다. 분리된 폴더에서 패키지를 열어 서버의 시작과 스킬 읽기를 확인한다.

실제 Codex에서 풀이·채점을 맡기거나 Windows 설치 앱에서 알림을 확인하는 일은 남아 있다. 이 비교는 제품 AI 호출 없이 진행했다.
