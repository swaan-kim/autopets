## 다음 확인

1. 오래된 관측의 연결만 앱에서 해제한다. DB 기록과 명시적 A/B는 보존한다.
2. 설치된 연결 도구로 원래 요청한 저장 펫 ID·개정을 현재 채팅에 적용하고 재조회한다.
3. 화면 대상이 일치할 때 앱의 정상 종료 버튼으로 종료한 뒤 프로세스·포트·연결 파일 제거를 확인한다.
4. 설치 도구로 다시 열어 새 통신 정보, 같은 연결/설정, A/B 기록과 위치 보존을 대조한다. 새 AI 작업을 만들지 않는다.

이전의 연결 파일/리스너 불일치는 이번 기동에서 재현되지 않았다. 이를 수정 완료로 표시하지 않는다. 오류 안내 변경은 개발 소스에만 반영돼 있으며 설치된 번들을 임의로 고치지 않았다. 새 검증 배포본에 포함해야 한다. 현재 연결 복구 및 정상 재시작은 위 조건이 충족될 때까지 미완료다.
