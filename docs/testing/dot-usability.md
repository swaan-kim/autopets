# 시작 화면과 연결된 펫 사용성 검사

2026-10-01. Dot 참고 화면의 여백·정보 순서·단일 주 행동을 AutoPets의 기존 흐름에 적용했다. 펫 자산과 역할, 계획 Luna/low 및 제작 세 프로필, Codex 연결과 저장 계약은 유지했다. 화면 개선을 실제 프롬프트 전달이나 모델 실행의 성공으로 계산하지 않는다.

## 요구사항과 근거

| 요구사항 | 구현·검사 근거 | 판정 |
| --- | --- | --- |
| 펫과 맡길 일을 먼저 이해 | 큰 기존 펫 미리보기, 짧은 역할 설명, 원본 스킬 출처 링크 | 렌더링 확인 |
| 단계마다 다음 행동 하나 | 내 펫 → 연결 → 시작, 준비 중 배경 카드/목록 숨김 | UI 검사 통과 |
| 모델 용어를 몰라도 설정 선택 | 가볍게·표준·꼼꼼하게 라디오, 키보드 화살표, 기본값 가볍게 유지 | UI 검사 통과 |
| 연결 범위 이해 | Codex 필수, Figma 기본 꺼짐, 준비/복사와 실제 연결 구분 | UI 검사 통과 |
| 실수 후 이어서 사용 | 뒤로/설정 방문 후 선택 유지, 저장·복사 실패, 최신 개정 재조회, 중복 클릭 | UI 검사 통과 |
| 연결된 작업의 다음 행동 확인 | 상태·다음 행동·Codex 작업 열기, 관리/실행 근거 접기 | UI 검사 통과 |
| 작은 화면에서도 탐색 | 992×688, 축소 794×550·661×459, 낮은 높이에서 페이지 스크롤, 주 버튼 접근 | 브라우저 렌더링 통과; 실제 Windows 배율은 별도 |
| 기존 동작 유지 | A/B 격리, 오류/미확인의 거짓 완료 방지, 개정 충돌, 복사만 수행, 오버레이 별도 스타일 | 회귀 UI 검사 통과 |

`pnpm build`와 `pnpm test:ui`의 55개 시나리오가 통과했고 페이지 오류는 0이다. 컴팩트 화면에서 고정 헤더/하단 버튼이 본문을 누르는 문제를 확인해 높이 560px 이하에서는 페이지 스크롤로 수정하고 다시 검사했다. 주 행동의 글자 대비와 작은 화면의 메뉴/종료 버튼도 확인했다.

기존 설치형 Windows 검사는 새 메뉴 이름 **더 보기**를 찾도록 조정했다. 과거 설치기를 다시 검사할 때는 이전 이름도 식별한다. 이 변경은 기존 설치본의 실패 결과를 소급해서 바꾸지 않는다.

## 설치형 확인과 사용자 흐름

현재 PC 설치본은 `2b4420c`이며 아직 이 화면 개편을 포함하지 않는다. 새 Windows 빌드·패키지·화면·기존 데이터 보존을 확인한 뒤 이 항목을 갱신한다. 새 설치 전 현재 앱과 데이터를 보존한다. 설치 차단이 생기면 보호 설정을 바꾸거나 성공으로 기록하지 않는다.

실제 AI 시험은 [사용자 정상 흐름](oneflow-happy.md)에 따라 별도로 진행한다. 현재 누계 42/55, A의 일반 계획 입력 대기다. 이 화면 작업과 CI에서는 실제 AI 실행을 하지 않았다. 프롬프트·계획 대기·모델/강도·결과물·채팅 복귀의 통과는 실제 사용 기록으로만 판정한다.

원본 UI 캡처와 로그는 Git 제외 `work/mvp-goal/20261001-dot-ui/`에 보존한다. 검사 재현은 `pnpm build`, `pnpm test:ui`, `pnpm test`, `pnpm verify:layout`이며 Windows 설치형 결과는 해당 CI 실행과 설치기 해시로 고정한다.
