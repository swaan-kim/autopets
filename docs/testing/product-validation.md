# AutoPets 제품 콘셉트 / 사용자 검증

> 과거 콘셉트 자료 · 2026-09-23 범위 정리: 이 문서는 상태 확인·창 이동 감소를 중심으로 만든 2026-09-20 홍보 목업과 인터뷰 초안이다. 아래 시작 질문·토큰 숫자·완료 장면은 그 시연의 구성으로, 현재 앱의 필수 절차나 실서비스 지원을 뜻하지 않는다. 공개 목업과 이미지는 보존한다. 이후 준비·조건 유지·설정 실수 방지로 확장한 방향과 검증 상태는 [팀 공유 요약](../product/team-brief.md)과 [진행 현황](../roadmap/project-status.md)에서 확인한다.

## 한 문장

**AI는 맡겨두고, 내 일에 집중하세요.**

작업 창을 열지 않아도 다른 앱 위의 작은 펫으로 지금 하는 일과 확인할 순간을 살펴본다.

**대상:** Codex에 리서치·문서 작업을 맡기고 다른 업무를 병행하는 비개발직 실무자.

**불편:** 일이 진행되는지, 응답이 왔는지, 내 결정이 필요한지 확인하기 위해 작업 창을 반복해서 열고 해당 작업을 찾는다.

**제안:** 채팅에서 부른 작은 픽셀 강아지가 독립 창으로 머무른다. 현재 단계와 확인할 순간을 알려주고, 누르면 관련 작업 정보를 펼쳐준다.

귀여움은 켜 두고 싶은 이유다. 핵심 제안은 **창 이동은 적게 · 확인은 필요할 때 · 여러 작업을 한눈에**라는 세 가지 편리함이다. 현재 활동과 확인 사유, 작업 이름을 함께 보여줘 상태를 보러 창을 반복해서 여는 번거로움을 줄이고자 한다. 실제 작업 자동 복귀는 연동 검증 중이므로 핵심 강점으로 약속하지 않는다. 시간·토큰 절감과 목표 성공률 향상은 아직 검증하지 않은 기대 효과이며, 결과 수치로 홍보하지 않는다.

## 체험 흐름

**펫 부르기 → 완료 기준 정하기 → 내 일 계속하기 → 필요할 때 확인 → 결과 확인**

펫이 보여주는 작업 단계는 **자료 조사 / 비교 초안 작성 / Notion 정리 / 완료**다. 고민·어지러움·화남은 별도 상황 표현이며 필수 작업 단계가 아니다.

1. `$autopets`와 작업 요청을 입력한다. 이미 같은 작업에 연결된 펫은 다시 만들지 않는다.
2. 기존 요청에서 완료 기준을 제안하고 확인받는다. 개입 시점은 ‘막히거나 결정이 필요할 때’가 기본이며 ‘주요 단계마다’를 선택할 수 있다.
3. 사용자는 Notion에서 회의를 준비한다. 경쟁사 비교와 고객 인터뷰 요약에 연결된 두 펫의 행위가 달라진다.
4. 펫을 누르면 완료 기준, 현재 단계, 계획 목록, 최근 갱신 상태가 나온다.
5. 어지러운 펫이 사용 기준 도달을 알린다. 누르면 **사용 10,400 / 알림 기준 10,000 토큰**과 **시연 데이터**를 함께 보여준다. 이 숫자는 권장 예산이 아니다. 알림은 작업을 멈추지 않으며 같은 기준 도달을 반복 표시하지 않는다. 시간 알림은 추가 설정에 남긴다.
6. 선택한 작업의 Codex 시연 화면으로 이동한다. 목업 바깥의 **다음 장면**에서 비교표와 출처 영역이 있는 예시 초안, 기뻐하는 펫을 보여준다. 결과를 확인한 뒤 회의 준비로 돌아간다. 실제 제품의 직접 복귀는 별도 연동 검증이 필요하다.
7. **전체 과정 재생**은 약 20초 동안 조사 → 고민 → 작성 → Notion 도구 사용 → 사용량 확인 요청 → 초안 완성을 보여준다. 자동 시연은 사용자의 화면을 강제로 전환하지 않는다. 오류 모션은 기본 성공 흐름과 별도로 체험한다.

## 표정과 문구의 약속

| 모션 | 표시할 의미 | 문구 |
|---|---|---|
| 대기 | 연결 후 시작 대기 | 준비되면 함께할게요. |
| 조사 | 자료 탐색 | 자료를 찾고 있어요. |
| 글쓰기 | 비교 초안 작성 | 비교 초안을 쓰고 있어요. |
| 고민 | 실행 중 생각 정리 | 생각을 정리하고 있어요. |
| 도구 사용 | Notion 등 도구 실행 | 도구 사용 · Notion |
| 어지러움 | 설정한 사용 기준 도달 | 계속 작업 중이에요. 살펴볼까요? |
| 화남 | 도구 오류 전용 | 도구 오류가 생겼어요. |
| 기쁨 | 예시 결과 완성 | 비교 초안이 완성됐어요. |

토큰이 많이 쓰였다는 이유로 화남을 표시하지 않는다. 움직임을 줄여도 대표 정지 프레임과 문구를 유지한다. 시연의 결과 완성은 실제 작업의 목표 달성을 자동 판정한다는 약속이 아니다.

## 제작물 사용법

- `index.html`: 인터넷 없이 열리는 그림 소개와 클릭 목업. **01 한눈에 소개**는 가로로 크게 열린다. **02 사용 흐름**, **03 필요할 때 확인**, **04 표정과 모션**을 둘러보거나 **직접 체험하기**로 조작한다. **전체 과정 재생**, **다음 장면**, 상태 예시, 추가 설정으로 성공 흐름과 예외 상황을 체험한다. 재설정하면 단계·알림·토큰 시연값이 초기화된다.
- `00-overview-wide.png`: 다른 앱에서 일을 계속하는 사용자와 작업 상태를 보여주는 두 펫을 중심으로, 세 가지 편리함과 전체 사용 흐름을 담은 가로 소개.
- `01-overview.png`: 같은 핵심 장면·세 가지 편리함·4단계 흐름을 세로로 담은 소개.
- `02-user-flow.png`: 시작 질문 → 조사 → 작성 → 도구 사용 → 완료. 마지막에 비교표와 출처가 있는 예시 초안을 보여준다.
- `03-benefits.png`: 어지러운 펫의 토큰 사용 기준 알림 → 같은 작업 확인 → 결과 도착과 업무 복귀.
- `04-motion-states.png`: 여덟 모션을 한눈에 비교하고 어지러움과 화남의 의미를 구별하는 상태표.
- `brand/autopets-mark.svg`, `brand/autopets-mark.png`: 강아지 심볼. `brand/autopets-logo.svg`, `brand/autopets-logo.png`: 심볼과 AutoPets 워드마크. 새 로고 SVG는 코드로 제작했다.
- `sprite-source.png`: 내장 ImageGen으로 생성한 원본 8프레임 아틀라스. 앱용 64×64 프레임은 소스 패키지의 `apps/desktop/public/assets/pet`에 있다.
- `asset-provenance.md`: 제작 프롬프트, 참고 출처, 이미지 처리 방식.

가로 소개 한 장은 1280×800, 세로 소개 세 장과 모션 상태표는 각각 1080×1350이며 같은 HTML에서 출력한다. 최신 묶음 파일은 `AutoPets-promo-v4.zip`이다. 기존 8프레임에 ImageGen으로 제작한 신규 5모션 각 2프레임을 더해 홍보용 18프레임을 구성한다. 글자와 배지, 단계 목록, 토큰 표시는 HTML로 만든다. 실행 중 이미지 생성이나 상태 판별용 모델 호출은 하지 않는다.

모든 소개 이미지는 제품 콘셉트와 시연 데이터를 표시한다. 실제 작업 자동 복귀는 연동 검증 중이다. 목업은 실제 Codex·Notion 작업을 수행하거나 외부로 전송하지 않는다. 소스 앱은 수신한 실제 데이터만 사용하며 목업 데이터를 연결하지 않는다.

## 첫 버전의 경계

자동 일시정지, 모델 변경, 지속적인 목표 이탈 코칭, 직접 승인·거절은 포함하지 않는다. 네이티브 앱의 토큰 알림은 실제 작업별 사용량이 연결되기 전까지 ‘측정 미연결’이다. 이번 목업의 토큰 설정과 숫자는 별도 시연 데이터로만 동작한다. 계정 전체 사용률을 작업별 토큰 사용량으로 표시하지 않는다. 기존 Codex의 권한·승인 정책, 네이티브 앱 상태 타입·토큰 기능·기존 펫 자산은 바꾸지 않는다.

계획이 바뀌어도 새 이미지를 만들지 않는다. 실제 계획과 도구 이벤트를 미리 정한 동작에 연결하고, 알 수 없는 행위는 ‘진행 중’으로 표시한다. 대화나 화면을 반복 분석하는 모델 호출을 추가하지 않는다. 스킬을 읽고 시작 질문을 처리하는 데에는 기존 Codex 호출 비용이 든다.

## 5분 인터뷰 — 설명보다 행동 먼저

**진행자 준비:** 대상은 최근 2주 안에 Codex에 리서치 또는 문서 작업을 맡긴 경험이 있는 사람 5명. 처음부터 귀여움·토큰 절약·생산성 향상을 강조하지 않는다. 설치나 결제 의향만으로 수요가 검증됐다고 판단하지 않는다. 참여자 모집과 메시지 발송은 별도 작업이다.

| 시간 | 진행 | 기록할 내용 |
|---|---|---|
| 0:00–1:00 | “최근 Codex에 일을 맡기고 다른 일을 했던 때를 떠올려 주세요. 진행이나 응답을 어떻게 확인했나요?” | 구체적인 작업, 확인 계기, 확인하려고 돌아간 경험. 그런 불편이 없었다는 답도 그대로 기록. |
| 1:00–2:00 | 가로 소개 `00-overview-wide.png`를 설명 없이 보여주고 “지금 무슨 일이 일어나고 있나요? 이걸 쓰면 무엇이 편해질까요?” | 독립 펫 인지, 두 작업 구분, 현재 행위와 전체 흐름 이해, 본인이 이해한 편리함. |
| 2:00–3:00 | **직접 체험하기**로 목업을 열고 “경쟁사 비교가 어디까지 됐는지 확인해 주세요.” | 첫 클릭, 단계 찾기, 다른 작업과 혼동, 도움 요청 여부. |
| 3:00–4:00 | 어지러운 펫 장면을 보여주고 “어떤 상황 같나요? 지금 무엇을 할 수 있나요?”라고 묻는다. 이후 같은 작업으로 돌아가 ‘다음 장면’에서 결과를 확인하게 한다. | 어지러움을 오류/중단으로 오해하는지, 토큰 시연 표시 인지, 같은 작업 복귀·결과 확인 이해. |
| 4:00–5:00 | “다음 주 어떤 업무에서 켜 둘 것 같나요? 오히려 방해가 되는 부분은요?” | 구체적인 재사용 상황, 기존 방식 대비 가치, 크기·움직임·알림 부담. |

선택 후속 질문: “어지러운 펫과 화난 펫은 어떻게 다르게 이해되나요?”, “토큰 숫자와 설명은 판단에 도움이 되나요?”, “고민하는 모습이 작업이 멈췄다는 뜻처럼 보이나요?”, “완성된 결과를 어디에서 확인하나요?”
