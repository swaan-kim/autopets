# Codex에서 부르는 펫 서비스 — 검수 기준

2026-10-23. 이번 구현의 통과 조건을 기록한다. 이 표의 준비 항목은 실행 증거가 아니며, 검사 결과는 실제 수행한 소스·명령·환경과 함께 추가한다.

## 기준과 예산

- 기본 경로: Codex에서 호출 → 앱 실행·펫 선택 → 정확한 채팅에 설정 적용 → 같은 채팅의 명시적 요청 → 진행·결과·복귀.
- 기존 실제 근거: [2026-10-21 설치형 검사](copy-free-installed-20261021.md). 내부 메시지 도구를 쓴 시험이며 일반 입력 통과로 대체하지 않는다.
- 실제 AI 기준 **77턴**. 이번 추가 최대 **8턴**, 누계 **85턴**. 부모·자식·재시험을 모두 센다. 코드 검사·UI 합성 검사는 AI 실행과 별도다.
- 사용자 관찰 **0/5**. 보안 정책을 유지한 새 PC 설치·서명 배포·Steam 적합성은 외부 관문으로 남아 있다.

| 배분 | 수행 | 관측 |
| --- | --- | --- |

| 2 | 앱에서 가용한 낮은 설정 적용 후 같은 채팅에 계획 요청 | 부모·자식 각각 1, 지침 준비·스킬 읽기·설정 기록, 파일 변경 0건 |
| 2 | 같은 계획에 명시적으로 구현 요청 | 부모·자식 각각 1, 새 결과·반환·펫 상태·다른 채팅 불변 |

| 2 | 원인 수정 후 필요한 검사만 | 같은 원인은 수정 후 최대 2회. 상한을 넘기지 않음 |

실행 기록 모델·강도 일치는 서버 내부 처리 모델까지 증명하지 않는다. 자식 최초 입력이 암호화되어 평문 대조가 불가능하면 해당 지침 증거를 독립 확인으로 승격하지 않는다. 계획 프롬프트 이행은 실제 Plan 제한과 다르다.

## 배포와 사용자 관문

1. 설치기·설치된 앱·연결 도구·스킬 버전·소스·해시를 같은 배포로 대조한다. 기존 앱 ID·설정·결과를 보존한다.
2. 이미 준비된 앱·연결을 반복 설치하지 않는다. 미서명 시험판과 서명된 일반 배포, 소스와 공개 파일의 시점을 구분한다.
3. 보호를 유지한 새 PC·일반 권한·개발 도구 없음·한글/공백 경로를 실제로 확인하기 전 일반 설치 통과를 선언하지 않는다.
4. Steam은 허용 분야·외부 Codex 의존성 적합성, 소유자 등록·비용·심사 이후 설치 위치·기존 설치 공존·업데이트·제거·데이터 보존을 검사한다. 스토어 등록이나 서명을 연결 지원의 근거로 삼지 않는다.
5. [사용자 검사 키트](campaign-user-study.md)의 현행 경로로 5명을 관찰한다. AI 없는 이해·복귀·재사용을 먼저 확인하며 실제 업무 비교·7일 자발적 재사용은 별도 조건과 예산을 확보한다.

최종 보고는 **제품 흐름 / 신뢰성 / 일반 배포 / 사용 편익 / 스토어 확장**을 따로 판정한다. 준비된 검사표·CI·예시 화면을 실제 사용자 관측으로 바꾸지 않는다.
