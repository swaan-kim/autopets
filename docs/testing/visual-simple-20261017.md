# 설명을 줄이고 결과로 이해하는 화면

2026-10-17, Windows 로컬 개발 환경. 기준 `96b80ac9875a7bbd58b1ed30fac62994dea70f7c`와 미커밋 화면 변경을 검사했다. 이전 첫 성공·동반 모션 변경과 별도 브리지 변경은 보존했다. 이번에는 프런트엔드만 수정했으며 API·DB·앱 식별자·실행 라우팅은 변경하지 않았다. **실제 AI 추가 0턴, 누계 71/72 유지.**

## 구현

- 첫 화면: **웹페이지, 펫에게 맡겨요.** / 요청 요약 → 펫 → 실제 제작 결과. `웹페이지 펫으로 시작`을 주 행동으로 유지했다.
- 실제 결과는 재생 전에 보인다. Enter로 확대하고 Escape나 닫기 버튼으로 돌아오면 원래 버튼에 초점이 복원된다. 기존 체험은 `과정 보기` 안으로 옮겼으며 접으면 멈춘다.
- 여섯 역할 카드: 작은 펫, 역할, 결과 썸네일, 출처 로고·스킬명, 즐겨찾기, 선택. 반복 소개와 긴 설명을 제거했다.
- 요청 화면: 할 일, 예시, 선택 작성 도움, 지금 필요한 준비/복사 버튼. 모델 설정·출처 상세·Figma·연결 관리·순서는 `자세히`로 접었다.
- 복사 후에는 **쓸 Codex 채팅에 붙여넣고 보내세요.** 한 줄로 안내한다. 복사와 링크 전달을 실제 접수나 실행으로 표시하지 않는다.
- 작업 카드의 정상 상태에서는 중복 설명을 줄였다. 오류·연결 불명·도움 꺼짐의 복구 안내는 유지했다.
- 저장 개정 충돌의 오류가 긴 상세 아래로 밀리는 문제를 재현했다. 주 버튼 아래에 오류와 `구성 다시 선택`을 두고 키보드로 최신 구성 선택창에 초점·스크롤을 전달하도록 수정했다.

## 글자 수 비교

같은 준비 완료 fixture, 992×688, 첫 방문, 상세 기본 접힘 상태로 비교했다. 첫 화면은 `.pet-experience`, 요청 화면은 `.pet-composer` 전체의 **기본 표시 UI 글자**를 세었다. 공백, 입력값, 숨긴 상세·장식, 결과 이미지 안 글자는 제외했다. 화면 위쪽만 세거나 사용자 입력을 지워 얻은 수치가 아니다.

| 화면 | 이전 | 이후 | 감소 |
| --- | ---: | ---: | ---: |
| 첫 화면 | 180자 | 78자 | 56.7% |
| 요청 준비 | 398자 | 88자 | 77.9% |

이는 **화면 설명량의 변화**다. 이해도·품질·작업 시간·비용 절감의 증거는 아니다. 기본 Codex와 동일 과제의 결과 비교가 없으므로 품질 Before/After나 절감률은 표시하지 않았다.

## 검사

- 화면 빌드(TypeScript/Vite) 통과.
- 여섯 역할의 초안·설정, 즐겨찾기·재사용, 준비 생략, 복사 실패·중복 방지, 오래된 저장 개정 복구, A/B 격리의 화면 회귀 통과.
- 결과 확대·Escape·초점 복귀, 상세의 키보드 열기, 이미지 실패 대체 표시, 동작 줄이기·숨긴 모션 정지 검사.
- 992×688에서 실제 결과와 시작 버튼, 준비 화면의 주 버튼이 초기 화면에 보인다. 794×550·661×459·375/390 너비에서 가로 넘침 없이 스크롤로 주 행동에 접근한다. **125%·150% 상당의 CSS 공간 검사이며 실제 Windows 배율 전환 검사는 아니다.**
- 전체 UI **57개 검사 묶음 통과·페이지 오류 0건**. 간결성 검사에 180/398자 기준의 절반 상한과 키보드 상세 열기를 포함했다. 저장 충돌 안내의 초기 화면 노출·복구 버튼의 초점 전달도 회귀 검사에 추가했다.
- 레이아웃·문서 링크·diff 공백 검사 통과. 이번 변경은 UI만 다뤘으므로 Node 연결 검사·Rust/Windows 빌드·재설치는 반복하지 않았다.

## 재현

```powershell
pnpm build
pnpm test:ui
pnpm verify:layout
```

이미 개발 서버가 1420에서 실행 중이면 아래로 같은 UI 검사를 실행한다.

```powershell
$env:AUTOPETS_SCREENSHOT='work/visual-simple-20261017/full/native.png'
node apps/desktop/tests/ui-smoke.cjs
```

간결성 검사만 실행하려면 `AUTOPETS_UI_VISUAL_ONLY=1`을 설정한다. 기본 글자 상한은 첫 화면 90자·요청 화면 199자다. 원본 전후 텍스트·진단은 Git 제외 `work/visual-simple-20261017/`에 있으며 공개 [전후 화면](../images/visual-simple-20261017/README.md)에는 개인 대화·입력을 포함하지 않는다.
