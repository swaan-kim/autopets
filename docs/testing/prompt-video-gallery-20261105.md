## 사용자 변화와 근거

기존 영상 카드 두 개는 정지 참고 이미지였다. 이제 실제 AI 영상 두 개를 상세에서 재생하고, 장면 변경 요청을 기존 영상 프롬프트 펫 설정에 담는다. 이미지/영상 분류와 기존 저장·적용·정확한 채팅 복귀 계약을 유지한다.

제작자가 원본 페이지에 선언한 CC0 1.0에 따라 가져왔다. Commons API의 대표 라이선스 표시는 Public domain이며 제작자 페이지의 CC0 선언도 확인했다. 원본 SHA-1을 다운로드 바이트와 대조했고, 제품 자산의 SHA-256·출처·포스터 정보를 `apps/desktop/public/assets/prompt-videos-v1/manifest.json`에 보관한다. 영상·워터마크는 수정하지 않았으며 포스터는 원본 0.5초 프레임이다. 한국어 요청은 AutoPets가 작성한 장면 변경 예시이며 원문 프롬프트의 인용이나 동일 결과 재현 보장이 아니다.

[Runway Explore](https://runway.com/explore)의 결과 우선 탐색을 참고했다. UI·문구·매체를 복제하지 않았고 이번 영상은 위 제작자의 공개 결과다. AutoPets 실행·스킬 결과·품질 검증으로 표시하지 않는다.
