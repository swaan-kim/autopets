# 2026-10-13 — 첫 체험과 함께 일하는 펫

## 범위와 구현

`96b80ac` 이후 작업 공간의 프런트엔드 변경이다. 기존 연결 오류 처리 등 미커밋 변경은 보존하고 이번 변경과 섞어 수정하지 않았다. 첫 방문과 웹페이지 제작 펫에만 적용하며 기존 공개 API·SQLite·앱 식별자·라우팅은 변경하지 않았다.

- 첫 화면: 짧은 요청 → 준비 → 계획 → 사용자 확인 대기 → 제작 → 결과. **예시 체험**이며 연결 도구·스킬·모델을 실행하거나 채팅에 전송하지 않는다. 주 행동은 기존 웹페이지 준비 화면으로 이어지는 '내 일 맡기기'. 준비·복사·Codex에 전송하는 실제 단계를 표시한다.
- 실제 결과 예시: [10월 12일 검증](installed-core-20261012.md)에서 제작한 가상 행사 페이지의 캡처. 예시 재생을 보고 새 결과가 만들어졌다고 표시하지 않는다.
- 모션: 인사·눈 깜빡임·기지개·짧은 달리기·메모 보기·카드 내밀기·타이핑·완료 반응. 사전 제작 프레임을 Web Animations로 재생한다. 실시간 3D, 오디오, 실행 중 이미지 생성·주기적인 모델 호출은 없다.
- 사용자 반응: 기존 버튼에 잠시 가리키기/키보드 초점/누르기를 연결한다. 기존 클릭·초점·작업 카드 열기 동작을 가로채지 않는다. 목록의 웹페이지 펫은 가리키거나 초점을 둘 때만 재생한다.
- 실제 표시: 관리 카드와 오버레이가 같은 연결·실행 기록을 사용한다. 요청 접수는 준비 동작, 계획은 메모, 실행은 타이핑, 반환/계획 대기는 카드, 실패/연결 불명은 정지다. 교감 동작은 실행 상태를 바꾸지 않는다.
- 완료: 같은 출처·채팅·폴더·실행의 관측된 상태 전환에만 반응한다. 이미 완료된 기록을 처음 열거나 재연결할 때 축하하지 않는다. 공유 잠금과 로컬 해시 영수증으로 중복 반응을 억제한다. 잠금/저장소 실패에는 축하만 생략하고 결과 표시·작업은 유지한다. 예시는 실제 작업 영수증을 쓰지 않는다.
- 숨김·화면 밖·동작 줄이기는 프레임 재생을 중지한다. 새 자산을 읽지 못하면 기존 입체 펫→기존 픽셀 펫→이미지 없음 순서의 표시를 재사용한다.

새 동작은 웹페이지 역할에 한정된다. 나머지 다섯 역할과 기존 제작 펫의 자산·라우팅을 일괄 변경하지 않았다. 실제 사람의 반응을 확인한 뒤 확대한다.

## 자원 비교

같은 992×688 Chromium 검수 화면에서 펫 하나만 보이게 하고 이전/신규의 대기·작업 상태를 각각 **7초씩 3회** 측정했다. 매 표본은 새 브라우저 컨텍스트를 사용하며 로딩·초기 인사 후 시작한다. 아래는 중앙값이다. CPU는 CDP `ProcessTime` 증가량/벽시계 시간, 메모리는 GC 후 JS 힙이다. Windows 전체 CPU·앱 작업 집합·GPU 메모리와 다르다.

| 상태 | 기존 CPU 시간 비율 | 신규 CPU 시간 비율 | 기존 JS 힙 | 신규 JS 힙 |
| --- | ---: | ---: | ---: | ---: |
| 대기 | 2.10% | 3.16% | 2.81 MiB | 3.19 MiB |
| 작업 | 2.56% | 3.77% | 2.81 MiB | 3.23 MiB |

이 표본에서 CPU 시간 비율은 약 1.1~1.2%p, JS 힙은 약 0.4 MiB 증가했다. 정지 포즈보다 움직이는 프레임의 비용이 있으므로 '성능 동일'로 표시하지 않는다. 새 시트·결과 이미지·manifest의 합계는 **705,992바이트**다. 화면 밖/숨김에서는 재생 Animation 0개를 별도 검사했다. 단시간 브라우저 측정으로 장시간 배터리·설치형 성능을 보증하지 않는다.

## 재현

```powershell
pnpm dev
# 다른 백그라운드 셸에서, 이미 실행한 개발 서버 대상으로:
$env:AUTOPETS_UI_COMPANION_ONLY='1'
node apps/desktop/tests/ui-smoke.cjs
Remove-Item Env:AUTOPETS_UI_COMPANION_ONLY
node apps/desktop/tests/ui-smoke.cjs
pnpm build
pnpm test
pnpm verify:layout
```

개발 서버가 없다면 `pnpm test:ui`로 서버 시작·전체 검사·종료를 함께 수행한다. 모션 비교는 `/tests/pet-motion-preview.html`(기존)과 `/tests/pet-motion-preview.html?companion=1`(신규)에서 가능하다. 둘 다 상태 예시이며 실제 AI 실행이 아니다.
