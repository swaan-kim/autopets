# 사용자 검증 준비

대상: 기본 AI 설정으로 리서치·문서 업무를 하는 비개발직 실무자 3–5명. 모집·발송은 이번 구현 범위 밖이다.

## 시연 전

최근 AI 작업에서 상태를 확인하러 돌아가거나, 조건을 다시 설명했던 실제 경험을 묻는다. 어떤 업무였는지, 어디서 불편했는지 먼저 듣는다.

## 설명 없이 해볼 일

1. 평소처럼 경쟁사 비교 초안을 요청하고 펫이 무엇을 도왔는지 말해본다.
2. 비교 조건을 바꾸고 펫의 기억한 조건을 확인한다.
3. 작업 방식을 꼼꼼하게로 바꾸고 언제 반영되는지 설명한다.
4. 다른 문서 작업과 경쟁사 비교 작업을 구별하고 필요한 작업으로 돌아간다.
5. 이번 채팅의 자동 도움을 끄거나 기록을 지운다.

첫 자동 도움 앱이 준비되기 전에는 기존 공개 콘셉트로 위 기능이 작동한다고 설명하지 않는다. 시연 자료에는 제품 콘셉트·시연 데이터를 표시한다.

## 마무리 질문

- 다음 주 자신의 어떤 업무에서 쓸 것 같은가?
- 펫이 도움이 된 순간과 방해된 순간은 어디인가?
- 자동으로 정리한 내용 중 믿기 어렵거나 수정하고 싶은 부분은 무엇인가?

관찰 기록: 도움 이해 / 조절 이해 / 작업 구별 / 복귀 / 반복 설명 여부 / 구체적 사용 상황 / 방해 요소.

탐색 기준은 5명 중 4명이 도움과 조절을 이해하고 3명이 사용할 실제 상황을 설명하는지다. 시장 수요·토큰 절감·성공률 증명으로 해석하지 않는다. 품질 비교는 목표·조건 반영, 근거, 수정 횟수를 같은 작업 기준으로 기록한다.
