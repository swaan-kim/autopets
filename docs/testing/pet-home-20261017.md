# 펫과 만나고, 일을 맡기는 시작 경험

2026-10-17. Windows 로컬 소스 `96b80ac9875a7bbd58b1ed30fac62994dea70f7c`와 기존 미커밋 변경 위에서 작업했다. 새 변경은 홈·탐색·요청 화면과 예시 자산이다. 공개 API·DB·앱 식별자·모델 라우팅은 유지했다. 기존 브리지 변경과 사용자 자료는 보존했다.

**실제 AI 시험 추가 0턴, 누계 71/72 유지. 이미지 제작 1회/최대 2회.** 신규 설치·호스트 변경·공개 배포는 수행하지 않았다.

## 달라진 흐름

1. **홈:** 대표 펫과 “무엇을 도와줄까요?”, 할 일 입력, `펫 찾기`와 `펫 둘러보기`. 인사 반응은 입력창에 초점만 옮긴다.
2. **찾기:** 여섯 역할의 이름·설명·로컬 키워드를 대조한다. 명확한 후보만 미리 선택하며 복수·불명확 요청은 사람이 고른다. 다른 펫으로 바꿀 수 있고 추천 자체는 저장·연결·실행하지 않는다.
3. **선택:** 결과 예시·짧은 용도·GitHub 로고와 스킬 출처를 먼저 보고 `이 펫으로`를 누른다. 즐겨찾기·저장 구성은 `펫 고르기 → 내 펫`에서 재사용한다.
4. **준비:** 작은 펫 머리말과 요청 입력에 집중한다. 준비한 연결을 반복하지 않으며 저장·개정 재조회 후 요청을 복사한다. 붙여넣기·전송은 기존 Codex 채팅에서 사용자가 한다. 등록 대상이 있을 때만 정확한 채팅 열기를 제공한다.
5. **복귀:** 홈의 `이어서 할 일`은 확인 필요 → 진행 중 → 최근 결과 순서다. 링크 전달만으로 도착·접수·실행을 확정하지 않는다.

홈에서 시작한 요청은 역할별·저장 구성별 초안과 별도의 세션 초안이다. 기존 초안을 조용히 덮어쓰지 않는다. 준비 화면을 열어도 탐색 화면은 숨긴 상태로 보존해, 돌아왔을 때 선택·후보·내 펫 탭·초점을 유지한다. 개인 입력을 새 DB 필드나 진단으로 수집하지 않는다.

검사 중 저장 충돌의 복구 버튼이 화면 아래에 가려지는 문제와, 준비 화면에서 돌아올 때 목록의 `전체` 분류가 선택한 역할의 분류로 바뀌는 문제를 고쳤다. 오류는 초점을 빼앗지 않고 복구 행동까지 보이도록 스크롤하며 사용자 분류 선택은 유지한다. 같은 상단 메뉴를 다시 눌러도 준비 화면을 벗어날 수 있고, 작성 중인 초안은 보존한다.

분류의 체크 표시가 버튼 이름에 섞이던 접근성 문제도 정리했다. 선택 상태는 `aria-pressed`로, 버튼 이름은 `전체·일상·업무`로 유지한다. 저장 구성을 바꾼 뒤 준비 화면을 닫아도 해당 펫의 사용 버튼으로 초점을 돌려준다.

## 예시와 출처

- 가상 모루대학교 오픈캠퍼스 페이지를 새로 디자인했다. 큰 행사 사진·제목·날짜·방문 안내가 중심이다. [실행 가능한 로컬 HTML](../../apps/desktop/public/assets/design-example-v1/index.html), [제작 근거와 프롬프트](../../apps/desktop/public/assets/design-example-v1/README.md).
- 새 예시는 **디자인 예시**다. 실제 펫 실행 결과나 스킬 개선 효과가 아니다. 기존 천문학과 실제 실행 캡처는 `companion-v1/verified-web-result.webp`와 기존 검증 기록에 보존했다.
- 앱에서는 데스크톱·모바일 렌더를 전환하고 확대한다. 네이티브 앱의 `frame-src 'none'`을 유지하므로 HTML iframe을 넣지 않았다. 독립 HTML은 파일로 직접 열 수 있다.
- 나머지 역할은 핵심 출력 한 부분을 읽을 수 있는 글자와 구조로 표시한다. 가짜 품질·속도·비용 비교 수치를 넣지 않았다.
- Pretendard Variable v1.3.9 원본 2,057,688바이트를 [라이선스와 함께](../../apps/desktop/public/assets/fonts/pretendard/README.md) 로컬에 묶었다. 본문 14–16px, 보조 정보 12px 이상을 기준으로 작업 흐름을 정리했다. 실행 중 외부 폰트·이미지 요청은 없다.

용도별 발견·출처 확인은 [Raycast](https://developers.raycast.com/basics/install-an-extension), 미리보기와 사용 분리는 [Framer](https://www.framer.com/marketplace/templates/tenora/), 확인할 일 우선 표시는 [Linear](https://linear.app/docs/inbox)의 공개 흐름을 참고했다. 타 서비스의 자산·템플릿을 복제하지 않았다.
