# 사용자 정상 흐름 — 지침·모델·강도 확인

2026-10-01 승인 기준. 사용자는 화면과 기존 Codex 채팅을 직접 조작하고, 검사 담당자는 연결·실행·파일 근거를 대조한다. 이번 목표는 UI 제작 펫 하나로 계획 → 구현 → 같은 채팅 복귀 → 결과 확인까지 마치는 것이다.

## 현재 판정과 실행 조건

**사전 검사 완료, 실제 체험은 설치 조건으로 대기 중이다.** 2026-10-01 현재 검증 설치기는 `NotSigned`이며 현재 PC의 Smart App Control은 켜져 있다. 확인한 GitHub 릴리스·산출물에는 더 새로운 서명 후보가 없다. 새 설치기를 실행하거나 기존 앱·보안 설정을 변경하지 않았다. [현재 설치본과 검증 기록](mvp-feasibility.md), [서명 준비와 다음 조건](../releases/code-signing.md)을 따른다.

- 정책이 허용하는 서명된 새 설치본의 출처·최종 해시·앱/제거기/설치기 서명을 확인한 뒤 정상 설치·실행한다. 서명 존재만으로 정책 허용을 가정하지 않는다.
- 정확한 전용 채팅 A와 작업 폴더를 호스트에서 다시 확인한다. 기존 입력 초안·파일·A/B 설정을 보존하고 `autopets-demo`가 없는 폴더를 사용한다. 충돌 시 기존 폴더를 삭제하거나 덮어쓰지 않는다.
- 시험은 Figma 꺼짐, **표준 제작**으로 시작한다. 제품 기본값인 가볍게는 바꾸지 않는다. 계획 Luna/low, 제작 Sol/low, 후속 검토 Sol/medium의 현재 가용성을 확인한다.
- 이미 스킬이 준비된 환경은 재사용하며 재방문 경로로 기록한다. 최초 사용자 설치·연결 준비까지 통과했다고 처리하지 않는다.
- API·DB·설치 식별자 변경이나 새 기능 추가는 없다. 재현된 결함이 있을 때만 수정하고 영향받는 검사를 수행한다.

## 사용자 행동과 확인표

| 단계 | 사용자가 할 일 | 검사 담당자가 확인할 것 |
| --- | --- | --- |
| 1. 펫 선택 | **이 펫으로 시작**, 상세의 제작 설정을 **표준**으로 선택 | 기반 스킬·계획/제작 설정 표시, Figma 꺼짐, 저장된 펫 ID·개정 |
| 2. 준비 | **Codex에 펫 준비** 또는 이미 준비됐으면 **채팅에서 시작하기** | 실제 스킬 준비와 채팅 연결을 구분. 안내 버튼 위에 오버레이 없음 |
| 3. 계획 요청 | **시작 요청 복사** 후 A에 원문 그대로 직접 전송 | 펫 ID·개정·전체 채팅 ID·폴더 일치, 계획 자식 1회, Luna/low, 첫 자식 입력의 지침 |
| 4. 계획 읽기 | 행사 페이지 계획 확인 | 소개·일정·신청 안내·모바일 구성이 있고 과제 파일 변경 0건. 펫은 **계획 확인 필요** |
| 5. 구현 | 같은 A에서 **그대로 구현해줘** 전송 | 새 자식 1회, Sol/low로 전환, 현재 계획·역할·스킬·요청 전달, `autopets-demo` 결과 생성, 기존 파일 보존 |
| 6. 복귀 | A에 `AP-HAPPY-DRAFT — 전송하지 않음` 초안을 남기고 다른 창으로 이동한 뒤 **Codex 작업 열기** | 기존 A의 전체 ID에 실제 도착, 초안 보존, 새 채팅/자동 전송 없음. OS 전달 안내만으로 통과하지 않음 |
| 7. 결과 | Codex가 반환한 결과 링크 열기 | 브라우저에서 가상 행사 페이지가 열림. 소개·일정·신청 안내 포함, 데스크톱 및 390px 폭에서 내용 잘림·가로 넘침 확인. 실제 등록/개인정보 수집 없음 |
| 8. 강도 변경 | 전송하지 않은 시험 초안을 지운 뒤 펫 설정을 **꼼꼼하게**로 변경하고 검토 요청 전송 | 같은 Sol에서 low → medium, 검토 자식 1회, 역할·검토 요청 전달, 과제 파일 변경 0건 |
| 9. 마무리 | 검토 결과 확인 | 사용자 후속 변경이 없으면 A 표준으로 복원. 시험 초안은 시험 문구가 그대로일 때만 정리. 기존 앱 상태·사용자 입력을 임의로 변경하지 않음 |

검토 요청은 **“제작 펫으로 방금 결과를 검토해줘. 파일은 수정하지 마.”**를 사용한다. 꼼꼼하게 설정은 추론 강도이며 읽기 전용 권한을 강제하지 않는다. 따라서 실제 자식 입력에 이 요청이 전달됐는지와 파일 불변을 함께 확인한다.

각 실행 전후 B의 설정·기록이 그대로인지 확인한다. 펫의 계획 중 → 계획 확인 필요 → 제작 중 → 결과 확인 → 완료 표시를 기록하고, 요청값과 호스트 실행 기록·결과 반환이 일치해야 완료로 인정한다. 단계별 소요 시간과 사용자가 별도 설명을 필요로 한 지점도 남긴다.

## 지침·라우팅 증거 구분

| 확인 대상 | 필요한 근거 | 성공으로 대신할 수 없는 것 |
| --- | --- | --- |
| 지침 준비 | 저장 펫의 instruction·선택 스킬·현재 단계가 `prepare` 반환값에 포함, UTF-8 3KB 이하 | 지침 문자열 생성만으로 전달 성공 |
| 실행 전 전달 | 해당 부모의 native 자식 실행 인수와 **그 자식의 최초 작업 입력**을 로컬에서 대조. 역할·단계·이번 요청·선택 스킬 참조가 전달됐는지 확인 | 부모 도구 출력에 지침이 보이는 것, 나중에 자식이 읽은 문서, 모델 자기 보고 |
| 지침 이행 | 계획 중 파일 불변·구현 대기, 명시적 구현 뒤 결과 생성, 검토 중 파일 불변 | 올바른 프롬프트를 보냈다는 사실만으로 이행 성공 |
| 스킬 읽기 | 고정 버전의 완전한 본문을 반환한 실제 도구 호출/결과, 같은 자식·턴과 일치 | 파일 존재·파일명 언급·“사용했다”는 답변 |
| 모델·강도 | 저장/요청 설정 → 정확한 자식·턴의 호스트 실행 기록: 계획 Luna/low → 구현 Sol/low → 검토 Sol/medium | 앱 선택값, 부모 모델, 모델 자기소개 |
| 채팅 복귀 | 실제 열린 전체 채팅 ID와 전송하지 않은 초안 보존 | “Codex에 열기를 요청했어요” 안내 |

`auditDelegatedTurn`과 기존 턴 검사는 대상·모델·강도·완료를 확인하며 프롬프트 내용은 반환하지 않는다. 이 검사 성공을 첫 지침 전달 증거로 확대하지 않는다. 첫 입력은 실제 반환된 자식 경로를 정확한 부모·폴더·시각과 연결한 후 해당 기록만 로컬에서 비교한다. 필요한 입력을 호스트가 노출하지 않으면 실행 전 전달은 미검증으로 남긴다.

원본 대화는 복사·공개하지 않는다. 지침 대조 결과는 길이·해시·필수 항목 일치 여부와 해당 시험의 요청/자식/턴 식별자를 Git 제외 기록에 보관한다. 계획 프롬프트 이행은 실제 Plan 강제가 아니며 라우팅은 부모 채팅의 설정 변경이 아니다. 호스트 실행 기록이 서버 내부 처리 모델까지 증명한다고 주장하지 않는다.

## 사전 검사 결과·예산·재개

연결·준비 지침·고정 프로필·스킬 근거·정확한 자식 기록에 관한 기존 **22개 독립 검사 통과**. 합성 입력과 대체 연결을 쓰는 검사이며 새 설치본의 실제 전달·응답·사용자 흐름은 아직 실행하지 않았다.

```powershell
node --test integrations/codex/tests/pet-connection.test.mjs integrations/codex/tests/pet-resources.test.mjs integrations/codex/tests/delegation.test.mjs integrations/codex/tests/turn-audit.test.mjs
```

실제 AI 누계 **42/55**, 이번 **0턴**, 예약 **0턴**. 기본 계획·구현 4턴과 읽기 전용 검토 2턴으로 누계 48/55를 예상하며, 부모·자식·추가 질문·재시험을 모두 실제 사용량으로 센다. 이후 Figma 4턴, 끄기·복구 2턴, 재시험 1턴을 남긴다.

서명된 정책 호환 설치본 확보 후 설치·실행을 확인하고 **단계 1**부터 사용자가 진행한다. 단계 전환은 앞 단계 근거가 확인된 뒤 안내한다. 실행 여부가 불명확한 요청은 재전송하지 않고 같은 작업부터 조회한다. 오류는 해당 단계에서 기록하며 같은 원인은 수정 후 최대 두 번만 재시험한다. 자연어 호출과 스킬 직접 선택 성공을 구분한다.

기본 흐름·지침 전달/이행·모델 전환·강도 변경·복귀를 각각 판정한다. Figma, A→B→A 교차 복귀, 개별 숨김 메뉴, 끄기·재시작은 별도 검사다. 이 정상 흐름을 마치면 기록하고 멈추며 기능을 확장하지 않는다. 원본 설치 조건·파일 참고 스냅샷·검사 로그·예산·재개 위치는 Git 제외 `work/mvp-goal/20261001-happy/`에 있다.
