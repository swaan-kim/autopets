# 발표자료 선택과 계획 검수

비교 기준은 #125와 #135를 반영한 main이다. Windows Chromium, 가상 채팅과 가상 발표 요청, 배율 100%에서 같은 화면을 열었다. 비교 창은 1280×900이고 작은 창은 390×844다.

- [이전](../changes/104/before-plan.png) · [추천받기](../changes/104/after-plan.png) · [선택 항목 펼침](../changes/104/after-options.png) · [작은 창](../changes/104/after-narrow.png)
- 합성 UI에서 추천받기, HTML, Figma, PPTX 선택이 요청에 각각 전달되고, 사진 없이 시작할 수 있는지 검사했다. 다른 펫에서 발표 설정이 보이지 않고 돌아오면 작성하던 값이 남는지 확인했다. 키보드로 선택 항목을 펼칠 수 있다.
- 레시피와 Codex·MCP 읽기 검사에서 발표자료에만 계획 확인 규칙이 전달되는지 확인했다. 이전 1.0.0과 새 1.1.0의 스킬 읽기, 보관본과 패키지 무결성, 저장 펫 개정 검사를 수행했다.

실제 Codex 대화에서 계획을 추천받아 편집하거나 Figma·PPTX 결과를 만들어 열어보는 일은 남아 있다. 사진을 첨부할 경우 사용자의 AI 채팅에서 첨부하며, 앱에서 사진을 저장하는 기능은 없다. 현행 설치본과 새 배포는 이 비교에 포함되지 않는다.
