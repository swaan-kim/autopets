Issue #29, 담당·통합 @swaan-kim, PR #30의 후속이다. 설치 리소스 비교 기준은 `8867226a6f65a0e96c2062d0a90d0f2b83a10c01`이며 변경 소스와 원격 Windows 검사는 PR의 최종 head를 따른다. 아래의 패키지 자동 검사와 실제 AI 호스트 시험을 구분한다.

## 설치 패키지의 누락과 수정

기존 Windows connector는 Codex 연결기와 Node를 포함했지만 `integrations/mcp/server.mjs`와 `client.mjs`를 수집하지 않았다. 소스 체크아웃에서는 실행되지만 설치 폴더의 같은 경로에서는 `MODULE_NOT_FOUND`로 종료한다. 현재 검토 설치본에서도 두 파일 부재를 확인했다.

`collectConnectorFiles`에 기존 MCP 실행 소스 두 개와 안내 파일만 고정 목록으로 추가했다. 두 모듈이 사용하는 브리지는 이미 패키지에 포함된다. 설치형과 독립 ZIP이 같은 수집기를 사용하므로 두 패키지의 무결성 원장에 함께 들어간다. MCPB 자산·서버 구현·도구 계약·새 의존성을 바꾸거나 호스트를 자동 등록하지 않는다.

새 회귀 검사는 저장소 밖의 한글·공백 경로에 설치 리소스를 준비하고, 그 위치의 MCP 서버를 직접 실행한다. 변경 전에는 모듈 부재로 실패했고 변경 후 다음을 확인했다.

- STDIO 초기화와 기존 읽기 도구 두 개의 목록이 정상 응답한다.
- 가상 앱 연결 파일이 없으면 일반 앱 미실행 오류를 반환한다. 개인정보·로컬 경로를 출력하거나 Codex 설정을 생성하지 않는다.
- 포함된 MCP 파일을 변조하면 기존 패키지 검증이 거부한다.
- 기존 핀·라이선스·연결/수리·데이터 보존과 분리 ZIP 검사도 유지한다.

## 실제 Codex 연결 시험

Windows 앱 `26.1029.7803.0`, 실행 중 Codex 백엔드 `0.166.0-alpha.6`에서 소유한 합성 시험 채팅만 사용했다. 원본 화면·대화·설정·ID·폴더·인증값은 공개하지 않는다. 메타데이터 조회는 선택한 ID/폴더와 `includeTurns=false`로 제한했다. 시험 결과의 최신 원장은 Issue #29다.

| 후속 부모 요청 | 표면과 입력 | 확인한 결과 |
| --- | --- | --- |
| 1–5 | Work의 기존 연결/분리된 읽기 진단 | 종료 확인. 연결·지침 읽기 실패. 기본 위치 불일치와 명시적 위치에서도 실패한 범위를 구분 |
| 6 | 네이티브 CLI, 선택 ID/개정을 지정한 MCP | 실제 도구 응답의 개정·지침 해시 일치와 현재 요청의 프롬프트 작성 |
| 7 | 네이티브 CLI, 펫 이름만 지정 | 실제 목록 1회 → 유일한 이름 선택 → 현재 ID/개정 읽기 1회 → 지침 해시 일치와 프롬프트 작성 |
| 8 | 7의 채팅을 앱에서 다시 열고 후속 일반 입력 | 같은 시험 표식/장면과 요청 수신은 확인. MCP 도구 미제공으로 종료 |
| 9 | 이 PC에 읽기 MCP를 등록하고 같은 앱 채팅에서 요청 | 앱 설정의 등록명·명령/서버 경로는 확인. 실행 도구 메타데이터 검색 뒤 MCP 사용 불가로 종료 |
| 10 | 같은 정의를 앱에서 저장하고 원래 도구 이름으로 검색 | 별칭 필터에 의존하지 않아도 후보가 없음. 메타데이터 검색 뒤 종료 |

총 10회 모두 종료를 확인했고 펫 하위 작업·제작 이미지/영상 추가는 0회다. 과거 77턴과 별도다. 9·10의 코드 실행 도구는 도구 메타데이터 검색에만 쓰였으며 셸 실행이나 앱의 펫 읽기 호출은 없었다. 모델의 성공 문구로 실제 MCP 호출을 대체하지 않는다.

실증용으로 고정 소스 3개를 별도 사용자 앱 위치에 준비하고 기존 Node로 실행하는 MCP 한 개를 공식 CLI로 등록했다. 기존 MCP 10개와 나머지 설정 값을 대조해 보존했다. 공식 직렬화가 생략한 기존 빈 인수 목록은 복원했으며 정수/실수의 동등한 숫자 표기는 같은 값으로 비교했다. 설정 백업·시제품 원장과 경로는 비공개다. 이 설정은 제품 코드의 자동 등록·새 호스트 지원·일반 배포가 아니다.

앱의 등록 화면 인식과 채팅에서 실제 도구를 사용할 수 있는지는 별개다. [공식 MCP 안내](https://learn.chatgpt.com/docs/extend/mcp)의 재시작 단계를 확인하기 전에, 다른 작업을 중단하지 않도록 소유자에게 가능 여부를 확인 중이다. 답변 없이 앱을 종료하거나 같은 AI 시험을 반복하지 않는다. [공식 채팅 링크](https://learn.chatgpt.com/docs/reference/commands#chats)로 시험 채팅을 연 근거를 AutoPets 복귀 버튼에서 시작하는 전체 흐름의 통과로 확대하지 않는다.
