# 처음 보는 사람의 편익·동반감 검사

2026-10-13 준비. **참여자 0/5, 미실시.** 화면 구현이나 자동 검사로 아래 항목을 통과 처리하지 않는다.

## 1. 설명 없이 30초

기존 첫 화면과 새 첫 화면을 같은 992×688 조건으로 보여준다. 3명은 기존→신규, 2명은 신규→기존 순서로 보고, 기능 설명·추천 문구는 진행자가 덧붙이지 않는다. 모르는 답도 그대로 적는다.

1. 무엇을 맡길 수 있다고 생각하나요?
2. 평소 쓰는 AI와 비교해 어떤 수고가 줄어드나요?
3. 시작하려면 무엇을 누르고, 어디에 요청을 보내면 될까요?

각 항목은 정확/일부/모름으로 적고, 선택한 버튼·걸린 시간·잘못 누른 곳을 기록한다. '내 일 맡기기' 이후 Codex 준비·요청 복사·기존 채팅 전송이 필요함을 오해하지 않는지도 확인한다. **5명 중 4명이 세 질문에 정확히 답하면 소개 이해도 기준 통과.** 귀엽다는 반응만으로 사용 이유를 이해했다고 계산하지 않는다.

## 2. 15~20분 작업 체험

본인이 할 법한 작은 작업을 고르고 새 펫과 함께 사용한다. 기존 사용과 비교할 때 과제·완료 기준은 동일하게 둔다. 새 실제 AI 실행은 기존 71/72턴 상한을 넘기지 않으며, 추가 예산과 참가자 준비가 없으면 실행 단계는 대기한다. 미리 녹화한 시연은 실제 사용 검사로 대체하지 않는다.

- 실제 편익: 지침 작성·설정 선택·준비 조작 수, 결과 확인까지 시간, 재작업, 도움을 요청한 곳.
- 동반감: 함께 일하는 느낌, 지루함, 집중 방해를 각각 1~5점과 한 줄 이유로 기록.
- 행동: 펫을 가리키거나 누른 횟수, 숨김/동작 줄이기 사용, 스스로 다시 맡긴 일 여부.
- 마지막 질문: 다음에 무슨 일을 이 펫에게 맡기고 싶나요? 쓰지 않겠다면 가장 큰 이유는 무엇인가요?

개인 대화·계정·작업 내용은 수집하지 않는다. 익명 번호와 조작·의견만 기록한다. 설치 문제, 첫 화면 문제, 실제 편익 부족, 모션 방해를 구분한다.
