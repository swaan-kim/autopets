## 구현한 진단과 시험 환경

준비 훅은 상태 관측 훅과 분리했다. 옵트인한 단일 프로젝트에만 설치하며 추가 지침은 3KB, 현재 채팅 기록은 1KB 이하로 제한한다. 새로운 모델 호출이나 이미지 생성은 없다.

자동 테스트는 실제 Node child process와 로컬 시험 HTTP 서버를 사용한다. 두 작업 기록 분리, 잘못된 nonce/턴 거부, 중복 주입 방지, 자기 채팅 복구, 비활성 처리, 잘못된 입력/연결 실패 시 빈 JSON, 설치·제거 보존을 확인한다. 이는 **실제 Desktop 모델 전달 검증이 아니다**.

최종 로컬 검사: `node --test tests/*.test.mjs` **31개 통과**(기존 22개 + 신규 M1 9개), 실패 0개. 생성한 Windows 명령이 한글·작은따옴표 경로에서 실행되는 것도 확인했다. `git diff --check` 통과. UI·Rust 소스는 이번 변경에서 수정하지 않았으며 기존 CI 기록을 새 코드의 실제 Desktop 검증으로 재사용하지 않는다.

정식 개발 프로젝트에 관측 훅 8개와 준비 진단 훅 3개를 구성했다. trust는 변경하지 않았고 실제 채팅 기록은 0개다. 프로덕션 전역 자동 도움은 활성화하지 않았다.
