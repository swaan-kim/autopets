## 만든 것

Windows Codex를 쓰는 비개발 마케팅·운영 담당자의 반복 준비와 작업 재개를 시험하도록 별도 진입 화면을 만들었다. 기존 앱의 실행·저장·라우팅·상태 계약과 설치본은 바꾸지 않았다. 시제품은 작업을 실제로 수행하지 않으며 모든 화면에 가상 작업 표시를 유지한다.

| 장면 | 동작 | 증거의 경계 |
| --- | --- | --- |
| 처음 맡기기 | 요청 또는 예시 → 방법 상세 → 체험 문구 준비·복사 | 복사할 문구에 비실행용 표식. 자동 전송·접수 없음 |
| 작업 이어가기 | 계획 대기 A와 결과 B 중 선택 → 해당 가상 채팅 보기 | 작업명은 시제품의 사용자 지정 정보. 실제 채팅 도착·이름 저장 아님 |
| 지난 방식 | 같은 스킬·설정 + 빈 새 요청, 첫 요청과 별도 초안 | 이전 내용·계획 승인·완료 상태를 가져오지 않음 |
| 결과 확인 | 디자인 예시 확대·모바일 보기 → 지난 방식으로 새 일 | 디자인 예시는 이번 AI 실행 결과가 아님. 기존 완료 진입은 축하 재생 안 함 |

대표 펫·모션·Pretendard·기존 디자인 예시를 재사용했다. 완료 체험은 사용자가 연 가상 상태 전환에 한 번만 반응한다. 펫 숨김·동작 줄이기·초기화 확인을 제공한다. 데이터는 화면 메모리에만 존재하고 새로고침으로 사라진다. 원격 이미지·추적·계정·실제 채팅·모델 호출은 없다. GitHub 원본은 사용자가 출처 링크를 누를 때만 연다.
