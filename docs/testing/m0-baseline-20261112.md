# M0 기준선 — 지금 설치본으로 실제 한 번 돌려 보기 (2026-11-12)

한 번에 시작(#56)을 만들기 전에, **지금 설치된 앱으로 실제 Codex에서 일을 끝까지 맡기면 몇 번을 누르고 무엇이 일어나는지** 기록했다. 이후 변경은 이 숫자와 비교한다.

- 근거 수준: **실제 실행** (이 PC, 실제 AI 3턴)
- 앱: 설치본 0.1.0, 소스 `7f359de` (한 번에 시작 변경 전)
- AI: ChatGPT 데스크톱 앱의 **Work** 탭, 권한 설정 "전체 액세스", 모델은 앱 기본값 그대로
- 조작: 화면 조작 도구로 사람이 누르는 순서 그대로 진행. 입력문은 앱의 예시 문장 그대로
- 개인 경로·대화 원문은 남기지 않는다

## 확인된 것

1. **링크 전달은 동작한다.** "Codex 새 대화로 시작"을 누르면 ChatGPT 앱의 Work 탭에 새 대화가 열리고 요청이 입력창에 들어간다. 붙여넣기는 필요 없다.
2. **이 화면에서는 AutoPets 스킬 스크립트(`pet.mjs`)가 실행되지 않았다.** AI는 저장한 펫을 읽는 도구(MCP)만 한 번 불렀고, 지침을 반영해 부모 채팅에서 바로 답했다. AI 스스로 "펫을 현재 채팅에 실제로 연결하거나 스킬을 실행한 상태인지는 확인되지 않았다", "스킬은 참조 정보로만 확인됐고 실제로 로드되지 않았다"고 답했다.
   - 그래서 채팅 연결, 하위 작업, 모델·강도 지정, 스킬 본문 읽기, 실행 기록 대조가 모두 일어나지 않았다.
   - 앱은 일이 시작됐는지, 끝났는지 알지 못한다. "내 작업"은 비어 있고 펫은 반응하지 않는다.
3. **계획 멈춤은 지침대로 동작했다.** 발표자료는 계획 표를 보여주고 멈췄고, "그대로 구현해줘"를 직접 입력해야 제작이 시작됐다.
4. **결과 파일은 Codex가 정한 채팅별 폴더에 생긴다.** 프로젝트를 고르지 않은 Work 대화는 `문서\Codex\<날짜>\<채팅 이름>\outputs\`에 저장했고, 채팅에 "발표자료 열기" 링크를 줬다. 앱에는 이 위치가 전달되지 않는다.
5. **브라우저 확인은 실패했다.** AI가 "브라우저 보안 정책이 로컬 파일 열기를 차단해 글자 겹침과 슬라이드 이동을 확인하지 못했다"고 알렸다.
6. **승인 창은 뜨지 않았다.** 다만 이 PC는 "전체 액세스" 설정이다. 기본 권한 설정에서는 다를 수 있어 미확인이다.

## Claude Code에서 본 것

- Claude 데스크톱 앱의 Code 탭 세션에서 AutoPets 읽기 도구(`autopets_list_pets`)를 실제로 불러, 이 PC에 저장된 펫 목록이 돌아오는 것을 확인했다. 앱에서 설치한 연결 파일(.mcpb)이 Code 탭에서도 쓰인다.
- **저장된 펫이 9개였고 같은 펫이 여러 개씩 중복돼 있었다**(같은 이름·역할이 2~3개). 시작할 때마다 새 펫을 저장해서 생긴 것이다. #57에서 같은 구성이 이미 있으면 재사용하도록 고쳤다.
- 앱에서 Claude Code로 넘기는 버튼은 없다. 지금은 채팅에 "AutoPets에 저장한 펫 찾아줘"처럼 직접 입력해야 한다.
- 문서로 확인한 것: 터미널의 Claude Code는 `claude-cli://open?q=…&cwd=…` 링크로 요청을 채워 열 수 있다(전송은 사용자). 데스크톱 앱의 Code 탭을 여는 링크는 문서에 없다. 이 PC에는 터미널용 Claude Code가 설치돼 있지 않아 링크 실행은 해 보지 못했다.

## 이 결과가 뜻하는 것

- 지금 사용자가 실제로 타는 경로는 **MCP 읽기 도구**다. Codex 전용 스킬 스크립트 경로(연결·하위 작업·기록 대조)는 이 화면에서 쓰이지 않는다.
- 따라서 "질문 한 번 → 끝까지"(#56)에서 실제로 효과가 나는 부분은 MCP 읽기 응답에 넣은 질문 묶음(`start`)이다. `pet.mjs --recipe`는 스킬 스크립트가 실행되는 환경에서만 쓰인다.
- 스킬 본문이 AI에 전달되지 않는다. 지금은 펫의 짧은 지침만 전달된다.
- 펫이 진행·완료·결과 위치를 알려면, AI가 상태를 앱에 알려 주는 통로가 필요하다. 훅이나 스킬 스크립트가 아니라 MCP 도구로 만들면 Codex와 Claude 계열에서 같은 방식으로 쓸 수 있다.
- 결과 위치는 우리가 폴더를 정하기보다, AI가 저장한 경로를 앱에 알려 주게 하는 편이 맞다.
