# 다시 재 보기 — 새 빌드를 설치해 핵심 흐름을 끝까지 (2026-11-12)

[M0 기준선](m0-baseline-20261112.md)과 같은 PC, 같은 방식으로 **앱에서 고르기 → AI에서 진행 → 펫 알림 → 결과 확인**을 다시 해 봤다. 이 문서는 그 결과와, 거기서 찾은 끊김을 적는다.

- 근거 수준: **실제 실행** (이 PC, Codex 대화 2건, AI 응답 5회). Claude Code는 일부만 확인.
- 앱: #57·#59·#61·#62·#64·#66·#68을 합친 CI 빌드(미서명 시험판). 설치 파일 해시는 빌드의 해시 목록과 일치.
- AI: ChatGPT 데스크톱 앱의 **Work** 탭, 권한 "전체 액세스", 모델은 앱 기본값.
- 조작: 화면 조작 도구로 사람이 누르는 순서 그대로. 개인 경로·대화 원문은 남기지 않는다.

## 확인된 것

1. **설치로 데이터가 사라지지 않았다.** 저장한 펫 9개가 설치 전후로 같았다. 앱은 메뉴의 "AutoPets 종료"로 끄고 설치했다.
2. **누르면 요청이 채워진 채 열린다.** 요청은 `AutoPets 스킬로 "<이름>" 시작해줘. petId=…, petRevision=…, recipe=….` 한두 줄이다. 같은 펫이 이미 저장돼 있어 새로 저장하지 않았다.
3. **시작 질문이 그대로 나왔다.** AI는 질문 묶음을 고치지 않고 보냈고, "기본으로"와 "1-③, 3-②" 같은 일부 답변을 기본값으로 채워 진행했다.
4. **펫이 알려 준다.** AI가 진행 알림 도구를 스스로 불렀다. Codex 앱을 다시 켜지 않아도 새 도구가 쓰였다. 질문·작업 중·완료가 펫 말풍선과 "내 작업"에 나타났다.
5. **결과를 바로 열 수 있다.** 파일을 만든 일은 말풍선과 "내 작업"에 "결과 열기"가 생겼고, 누르면 그 폴더가 탐색기에서 열렸다.
6. **화면 위 펫에서 한 줄로 시작할 수 있다.** "동아리 신입 모집 발표자료"라고 적자 발표자료 펫으로 맞춰 열렸다. 첫 시도는 새 대화가 열리지 않아 한 번 더 눌렀다. 자동 입력의 한글 조합 때문일 가능성이 있어 제품 문제로 확정하지 못했다.
7. **스킬 허브와 순서 변경이 설치본에 반영됐다.** "펫 고르기"의 첫 화면이 이미지·영상 예시가 아닌 펫 카드다. 허브 항목을 실제로 눌러 열어 보지는 않았다.

| 어디서 | 본 것 | 고친 방법 |
| --- | --- | --- |
| 할 일을 비우고 시작 | 선택 질문 3개에 답한 뒤 "공부할 주제를 보내 주세요"를 한 번 더 물음 | 할 일이 없으면 "무엇을 할지"를 1번 질문으로 함께 물음 |
| 계획 먼저 펫 | 질문 4개에 답했는데 계획 표를 보여주고 승인을 기다림 | 답이 곧 확인. 계획을 다시 승인받지 않는 규칙을 응답에 넣음 |
| AI가 승인을 기다릴 때 | 펫 상태가 "작업 중" | 답을 기다릴 때마다 질문 상태로 알리게 함 |

| 펫 카드 | 일이 끝났는데 "작업 연결 전 · 채팅 연결 대기 · 전달된 단계 없음" | AI가 알려준 일이 있으면 지금 상태 한 줄 |
| 펫 화면 | 시작 버튼 아래에 예전 방법 버튼 6개 | "다른 방법" 아래로 접음(#72) |

## 설치·연결에서 찾은 것 (아직 고치지 않음)

1. **예전 방식으로 등록된 Codex 읽기 도구는 새 버전이 되지 않는다.** 이 PC의 Codex 설정에는 11월 6일에 등록된 읽기 도구(0.1.0)가 있었고 앱의 소유 기록은 없었다. "연결 복구"는 "펫 읽기 도구는 확인이 더 필요해요"라고만 하고 그대로 뒀다(소유 기록이 없는 같은 이름 항목은 보존하는 규칙). 이 상태에서는 시작 질문, 스킬 본문, 진행 알림이 **하나도 Codex에 닿지 않는다.** 이번에는 설정 파일을 백업하고 그 항목(두 구역, 5줄)만 지운 뒤 "연결 복구"를 다시 눌러 앱이 새로 등록하게 했다. 사용자에게 보일 안내와 자동 처리 여부는 팀 결정이 필요하다.
2. **Claude는 연결 파일을 다시 설치해야 한다.** 이 PC의 Claude 연결 파일은 0.1.2다. Claude Code 세션에서 읽기 도구를 실제로 불러 보니 새 앱과는 통하지만 시작 질문·스킬 본문·진행 알림은 없었다. 앱의 "Claude에 설치"를 눌러 설치 창까지 띄웠고, 창의 확인은 사용자가 해야 한다. 앱은 업데이트 뒤 재설치가 필요하다는 것을 알려 주지 않는다.
3. **Claude Code로 시작.** 여는 AI를 Claude Code로 바꾸자 버튼이 "Claude Code에서 시작"이 됐고, 누르자 앱은 "Claude Code 새 세션에 요청을 넣었어요"라고 답했다. `claude://` 링크는 이 PC에서 Claude 앱으로 연결돼 있고 작업 폴더(문서의 AutoPets)도 만들어졌다. **열린 화면 자체는 화면 조작 도구로 볼 수 없어 확인하지 못했다.**

## 하지 않은 것

- #70·#72 변경 뒤 빌드의 실제 실행. 계획을 다시 묻지 않는지는 실제 AI로만 알 수 있다.
- Claude Code에서 질문 → 작업 → 완료 말풍선까지의 전체 흐름(연결 파일 재설치 뒤).
- 스킬 본문을 AI가 실제로 따랐는지의 대조. 결과물은 스킬이 정한 형식(HTML 5장)이었지만 본문을 읽어서인지는 구분하지 못한다.
- 기본 권한 설정에서의 승인 창 횟수, 허브 항목별 열기.
