# 로컬 기록과 설정 해석 확인 — 방향 재정리(#106)의 근거 (2026-11-22)

방향 재정리(#106)를 세우기 전에 확인한 사실과, 아직 확인하지 못한 것을 근거 종류별로 남겨요. **화면 조작과 AI 실행은 하지 않았어요.** 대화 내용은 읽어서 출력하지 않았고, 필드 이름과 숫자만 봤어요. 이 PC의 개인 설정값(어떤 모델을 쓰는지, 한도를 얼마나 썼는지)은 적지 않아요.

근거 표시: **[PC 기록]** 이 PC의 기록 형식을 직접 봄 · **[설정 읽기]** Codex가 설정을 어떻게 해석하는지만 봄(읽기 전용 호출) · **[문서]** 공식 문서 · **[소스]** 공개 소스 코드 · **[실행 필요]** 아직 실제로 확인하지 않음

## 확인 방법

- Codex 명령줄 0.166.0(Windows). 이 저장소의 읽기 전용 도우미(`integrations/codex/runtime/rpc.mjs`, `read-only.mjs`)로 `model/list`, `config/read`, `skills/list`를 불렀어요. 이 호출은 채팅을 시작하거나 설정을 바꾸지 않아요.
- 로컬 기록 파일은 줄의 종류와 필드 이름, 숫자만 출력하는 스크립트로 봤어요.
- 폴더 설정 확인용 임시 폴더는 확인 뒤 지웠어요.

## 이 기록으로 정한 것

- 모델 이름은 앱에 고정하지 않고, 단계별 후보를 계정 목록에서 골라요.
- 사용량은 앱이 연 채팅의 숫자 줄만 읽어요. 대화가 담길 수 있는 줄은 해석하지 않아요.
- "설정이 적용됐어요"는 실제 확인(V0~V2)을 통과하고, 그 일의 기록이 요청과 같을 때만 말해요.
