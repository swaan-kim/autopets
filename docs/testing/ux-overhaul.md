## 변경과 재현

기준 소스 `71410ef`, PR #21의 후속 변경이다. 기존 실행·저장·공개 API·DB·앱 식별자는 그대로 유지한다.

- 홈: 처음에는 할 일 선택, 재방문에는 확인 필요 → 진행 중 → 최근 결과 → 준비된 펫 순서. 최근 결과는 저장된 연결의 실제 실행 기록만 사용한다.
- 펫 고르기: 일상 3개와 업무 3개. 같은 입체 펫에 로컬 SVG 소품을 붙이고 설명용 결과 예시를 제공한다. 목록 모션은 정지한다.
- 작업 준비: 할 일·세 가지 실행 설정·필요할 때만 Codex 준비를 한 화면에 배치한다. 저장·재조회 후 요청을 복사하며 자동 전송하지 않는다.
- 내 펫: 즐겨찾기와 저장한 구성을 다시 사용한다. 역할 전환·뒤로 이동에도 이번 앱 세션의 초안을 보존한다.
- 상태·복귀: 기존 `ExplicitPet`과 정확한 대상·개정 확인을 재사용한다. 상태 이동 시 카드를 다시 만들지 않아 열린 관리 화면과 초점을 보존한다.

참고는 [Raycast Store](https://www.raycast.com/store)의 짧은 목적별 선택, [Linear Inbox](https://linear.app/docs/inbox)의 확인할 일 우선 구성, [Notion Marketplace](https://www.notion.com/templates)의 결과 예시·출처 확인이다. 제공받은 Dot 화면에서는 여백과 단계별 주 행동을 참고했다. 서비스의 실행 기능이나 자산을 복제하지 않는다.

## 캡처와 남은 조건

`work/ux-v2-{home,desktop,125-layout,150-layout,narrow,returning,my-pets}.png`는 합성 상태를 주입한 개발 화면이다. Windows CI의 review artifact에도 포함한다. 실제 생성 결과나 설치 앱 화면으로 표시하지 않는다.

AI 원장 기준은 이전 55/72턴 + 미소비 예약 1턴이다. 실제 시험 전에 최신 기록을 대조한다. 코드·화면 검사는 AI 턴이 아니며 이번 UI 구현에는 AI 작업 요청을 실행하지 않았다.

설치 성공, 화면 성공, 실제 채팅 연동, 보안 정책이 켜진 일반 사용자 배포는 각각 판정한다. 서명 자격·실제 Windows 배율·사용자 이해도 조건이 없으면 미검증으로 남긴다. Dot·Work·Jev·공유 사이트는 이번 범위에 포함하지 않는다.
