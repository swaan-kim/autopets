# 동일 설치본의 제거·재설치 검증

2026-09-25, 1번 설치 기본 작동 구간의 하위 검사. **별도 Windows CI의 설치·제거·재설치 및 테스트 데이터 보존 통과.** 사용자 PC의 앱·마우스·키보드·사용 중인 콘솔은 조작하지 않았다.

## 대상과 방법

- 기존 [Windows 빌드 산출물](https://github.com/swaan-kim/autopets/actions/runs/35863282348), artifact `10752596469`에서 설치기만 추출한다. 새 설치기를 빌드하지 않는다.
- 소스 `db06cb964be9824d8a975710f055fcfc1a1d0ed3`, PR 병합 빌드 `8b39f29f4bb373fda2637f65fa3af988883cb3b0`.
- 설치기 SHA256: `aedd45bc8cb71e8ffa5b338c6c3fb9ec8b2e811663b79da8710b7a8cab85c5da`, 244,097,822 bytes. 기존 검증 서명 상태 `NotSigned`이며 CI에서도 다시 기록한다.
- GitHub-hosted Windows의 기본 설치 위치와 기본 앱 데이터 위치를 사용한다. 기존 AutoPets 상태가 있으면 실패시키고 덮어쓰지 않는다.
- 자동 설치와 제거는 `/S`를 사용한다. 제거기는 등록된 경로의 원본을 호출하고 [Start-Process -Wait](https://learn.microsoft.com/en-us/powershell/module/microsoft.powershell.management/start-process?view=powershell-7.5#notes)로 하위 프로세스 종료까지 기다린다. 강제 종료·파일 수동 삭제로 성공을 만들지 않는다.
- 앱 저장소 코드를 사용하는 CI 전용 fixture가 채팅 1개·이벤트 2개, 완료 기준·알림·선호 설정·문맥·펫 배정·위치 파일을 만든다. fixture는 일반 테스트에서 제외되며 GitHub-hosted Windows에서 명시적으로만 실행된다.
