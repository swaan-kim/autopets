어디까지 사용할 수 있나요?

Windows 로컬 Codex에서 명시적으로 부르는 펫 작업이 대상이에요. 앱의 펫 선택·설정 적용, 하위 작업 실행, 같은 채팅 복귀를 대표 과제로 검사했어요.

펫 하위 작업의 설정과 계획 지침을 사용해요. 부모 채팅의 모델 변경, 실제 Plan 모드 강제, 모든 요청의 자동 처리는 지원하지 않아요.

앱 설치와 스킬 준비는 별개예요. 일반 입력·다른 PC 설치·사용자 편익은 별도 검증하며, 다른 AI와 Steam은 현재 지원 범위가 아니에요.
