# 2026-10-05 개발 화면

- [시작 화면](start.png): 실제 React 화면 코드에 합성 저장 상태를 넣은 브라우저 검사 화면. 현재 PC의 새 설치본 캡처가 아니다.
- [펫 상태 6개](pet-states.png): 실제 펫 컴포넌트의 개발용 상태 예시. 화면에도 예시임을 표시했다. 실제 AI 실행·작업 완료의 증거가 아니다.
- [동작 영상](pet-motion.webm): 같은 컴포넌트의 동작 줄이기 적용/해제 예시. 녹화 초반은 정지 상태이고 후반은 짧고 작은 움직임이다.

기존 크림색 강아지 특징을 유지한 투명 PNG를 제작 과정에서 1회 생성했다. 1536×1024 이미지의 512px 셀 6개를 사용한다. 앱 실행 중 이미지 생성·3D 엔진·AI 호출은 없다. 과거 픽셀 자산은 로딩 실패 시 복원용으로 유지한다.

개발용 모션 화면 재현: `pnpm dev` 실행 후 `/tests/pet-motion-preview.html`. 이 페이지는 Vite 개발 전용이며 앱 배포 진입점에 포함하지 않는다.
