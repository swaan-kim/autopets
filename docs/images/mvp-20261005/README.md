## 현재 PC의 실제 설치 앱

- [정상 재시작 직후](installed-after-restart.jpg): 검증 설치본 `079a1e1`의 실제 네이티브 화면. 기존 기록은 보존하고 연결은 재확인 필요로 표시한다.
- [B 기존 결과 복구 후](installed-recovered-b.jpg): 설치된 스킬이 과거 결과를 재확인한 화면. 새 자식 실행이나 새 UI 펫의 전체 흐름 성공을 나타내지 않는다.

위 두 캡처는 합성 화면이 아니다. 현재 PC의 보안 조건과 설치본 해시는 [검사 기록](../../testing/friendly-mvp.md)을 참고한다.

기존 크림색 강아지 특징을 유지한 투명 PNG를 제작 과정에서 1회 생성했다. 1536×1024 이미지의 512px 셀 6개를 사용한다. 앱 실행 중 이미지 생성·3D 엔진·AI 호출은 없다. 과거 픽셀 자산은 로딩 실패 시 복원용으로 유지한다.

개발용 모션 화면 재현: `pnpm dev` 실행 후 `/tests/pet-motion-preview.html`. 이 페이지는 Vite 개발 전용이며 앱 배포 진입점에 포함하지 않는다.
